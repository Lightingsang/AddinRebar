Prove gate/guard claims empirically: a scratch `net8.0-windows` console (UseWPF=true when the bridge is WPF) in the scratchpad with one `<ProjectReference>` to the bridge csproj, calling `XxxAnalyzer.Inspect(compiled.Script)` + `ScriptGuard.Check(code, GuardProfile.X)` + the run-time screen (`PathRefusals`) over a table of samples; `dotnet run` takes ~1 min and needs no host app. Quote the printed lines verbatim in the report.

**Why:** the phase-1 ETABS review (2026-09-17) found the tier walker missed `var m = sapModel; m.X.SetY()`, casts, `?.`, lambdas, and refused `StartsWith`/`Clear` — every claim was disputed-by-reading until the probe printed the verdicts. The phase-2 review (same day) found by probe what reading alone would have hand-waved: `args.Str("k", @"\\unc\fallback")` and a script-defined `class ScriptArgs` slip the path policy; `#r "C:\x.dll"` compiles under `ScriptOptions.Default` and runs a DLL's OAPI calls as tier R; `#load` bypasses the guard; `GetFullPath` normalises `\.\` / `\\` / `/../` *after* the forbidden-fragment check. The lead accepts findings with `file:line` + printed evidence; reasoning alone is treated as a hypothesis.

**How to apply:** any review of a script gate — write the probe first, then rank. Always include these samples: `args.Str(key, fallback)`, a script-defined class shadowing the engine type, a declared key absent from `args`, `#r`/`#load` directives (write the DLL/csx under `C:\Users\Public`, delete afterwards), `nameof(...)`, method group, `?.`, named args, raw/verbatim/const/interpolated literals, `.\`/`\\`/`../`/`\\?\`/ADS/drive-root path shapes, and a reflection sweep of the host wrapper against the tier table. Gotchas: if the bridge exe is running it locks `bin\` and the probe's ProjectReference build fails — build with `--no-dependencies` (uses the last bridge build; check source mtimes vs the DLL); nulling Roslyn `ScriptOptions` resolvers NREs — a directive scan (`root.GetReferenceDirectives()/GetLoadDirectives()`) is the workable fix; bash heredocs with C# escapes fail silently — write the probe with the Write tool. Never add the probe to the repo; the samples belong in the fix PR's theory rows.

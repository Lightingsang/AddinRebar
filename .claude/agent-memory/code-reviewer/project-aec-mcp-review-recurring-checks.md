Recurring defect classes in `HPAutoCad/HPAutoCad.Aec` tool reviews (phase A 7/10, B 6.5/10, C 6/10, D 5.5/10, E 5/10, F 5/10, G 5.5/10, H 5.5/10, I 6/10 — `plans/reports/code-review-2026-09-16-aec-phase-*.md`, `code-review-2026-09-17-aec-phase-{e,f,g,h,i}.md`):

1. **Default/max `limit` × item size vs the bridge's 64 KB cap** (`BridgeSettings.MaxOutputBytes`; overflow = head-as-text, not JSON). Breached in every phase: A `detect_geometry_issues` detail; B `classify_aec_entities` blocks with attributes; C `findReferences` (attributes uncapped, 500 × ~250 B) + `listDefinitions` + unbounded `handles` on read ops + **the error path of a 500-item batch** (`EditResult.Settle` copies every item error into `errors[]`, warnings per item). Measure the *failure* envelope too — for a write tool an unreadable envelope means committed entities with unknown handles. A Python `json.dumps` probe of a synthetic item × limit is enough.
2. **`count` vs "the total"**: phase A used `IssueOverscan = 4`; phase B returned early at `limit + 1`. Check the early-return path of every detector.
3. **`FirstOrDefault()` on `IReadOnlyList<Pt>`** (struct) yields (0,0,0) — wrong `locationMm`.
4. **Rule-set data**: wildcard infixes collide with STRUCT/COTAS/CUASO/ONGGIO/DAMPER/SANR; run rule sets over hostile layer names.
5. **System.Text.Json validation gaps**: JSON `null` into `List<string>` → NRE; unknown keys silently ignored unless `UnmappedMemberHandling = Disallow`.
6. **Write-path ordering (phase C)**: `Entity.SetDatabaseDefaults()` resets Layer/Color/Linetype/Lineweight/Visibility — any call after `LayerId`/`ApplyProperties` silently discards them (hatch create); `UpgradeOpen()` on an `AttributeReference` whose *own* layer is locked throws `eOnLockedLayer` even when the INSERT's layer passed; `UpgradeOpen` in a validation phase fires the bridge's `ObjectOpenedForModify` counter, so a refused atomic batch reports `changed.modified = N`.
7. **"success=false but committed"**: single-item ops (hatch update, setDynamic, detach) apply valid keys, collect errors, return `success=false` without throwing — the bridge commits. Grep every `result.Fail(` / `Success = false` that is not followed by a throw or an early return before the write.
8. **`EntityFilter.Matches([]) == true` used as an exemption list (phase D, 5.5/10)**: empty `exempt`/`exemptTypes`/`allowedTypes` → everything exempt → check silently disabled while `checkedTypes` says it ran. Grep `!EntityFilter.Matches(` on any list named exempt/allowed.
9. **Space merging**: `filter.IsEmpty` ignores `Space`; audit tools replace an empty filter with `Space="all"` (drops `{space:"model"}`) and run the pairwise geometry detector over model + every layout in one pass → title blocks in two layouts = `duplicate`. Also markup targets `space` (current) whatever space the issue's handles live in. Any tool that widens to "all" must group by `Space`.
10. **Table checks vs xref/hidden records**: `IsFromExternalReference` is true only for the xref BTR itself — nested `SITE|DOOR` records are `IsDependent`; `*ADSK_*` layers are `LayerTableRecord.IsHidden`; `ed.SelectAll` never enters block definitions (unused-layer claims).
11. **Uncaught `RegexMatchTimeoutException`** from user rule files → engine error → quarantine after 5 identical calls.
12. **Write tools with no cap on "how many things I touch" (phase E, 5/10)**: `structural_tag_members` tagged every member (300 → 74 KB, texts committed, envelope head-as-text); the read twin had `MaxMemberLimit` 120. Also the summary echoed each item 3× (`items`, `summary.marks`, `summary.written`). Every write tool needs a member cap + `maxCandidates`.
13. **Text index = TEXT/MTEXT only; INSERT values live in `record.Attributes`**: grid bubbles with attribute labels → no labels; a block member's `MARK` attribute is never the "existing mark" so `overwrite:false` overwrites it; "overwritten" never touched the old TEXT (drawing ends with two marks). Any "existing X near Y" feature: check attributes, keep the source handle, claim each text once.
14. **Nearest-within-radius with no direction test** (grid bubble to line end, mark text to member): a line without its own bubble took a perpendicular line's bottom bubble 2 421 mm away. Require on-axis / containment, not just distance.
15. **Reservations by string, banding by `Math.Round`**: `C01` kept + digits 1 → `C1` assigned; row bands split a row at odd multiples of 125 mm. Reserve numbers, cluster by gap.
16. **Predicates in verdicts**: `Intersects` includes touching → an opening sharing a column face is "cuts through column" (critical); collinear-exclusion at 1 mm lets a 2-mm-off duplicate beam "support" the original. Probe touching + near-duplicate for every geometric verdict.

17. **`SpatialRelation.Overlaps` holds on a shared boundary run** (`SpatialPredicates` returns true when `CollinearOverlaps > 0` or any vertex is inside *incl. on the boundary*): two tiled room outlines = `room_overlap` (phase F H2). Any "overlap" verdict on closed shapes must test interior overlap (strict vertex-inside or proper crossing).
18. **Face nesting / containment rules with boundary-inclusive `ContainsPointXY`**: a face whose ring runs around an attached inner enclosure "contains" every vertex of that enclosure → the room is dropped as `Nested`, only the closet survives (phase F H3). Probe: closet hung off a wall by one stub, and a free-standing shaft in a hall.
19. **Positional ids (`R-001`…) consumed by sibling tools that lack the inputs deciding the set** (tolerance, size floors, `maxCandidates`) — ids shift silently (phase F M4). Check every tool that accepts `xxxIds` takes the same detection args as the tool that lists them.
20. **Wall-graph tools and openings**: walls stop at doors in real plans; a bounded-face finder yields 0 rooms (single-line) or one merged room per floor (double-line with jambs) while the harness scene has no door (phase F H1). Also the overshoot heuristic "nearest wall's foot == junction" swallows a real gap beside a partition and misses angled overshoots (H5); `reach = 12 × roomGap` ignores `maxGapMm` (M1).
21. **Nested O(n²) over kept faces / O(tips × pieces) nearest scans** hide behind a `MaxSegments` guard: 10 000 faces = 80 s > the 60 s tool timeout; 4 000 tips × 18 000 pieces = 14 s uncancellable (phase F M10). Time the pure classes at the guard's limit, not at the harness scene.

22. **Graph tools test only the *ends* of a run against nodes (phase G H1)**: a valve/pump/VAV drawn on a continuous line is an `orphan_node`; the main and the branch ending inside the VAV are two networks. Probe: node centred on an unbroken run; run through equipment with a branch ending inside it.
23. **A shared node unions every system that touches it (phase G H2)**: supply + return + ducts through one AHU = one `mixed` network + a `mixed_system` issue per piece of equipment. Union through nodes per system; "mixed" only for run-to-run joins.
24. **Own-entity exclusion (`k == i`) hides self-gaps (phase G M7, same as F M3)**; and **per-group `Where` over the whole item list** (`groups × endpoints`) = 21 s at 20 000 disconnected runs while chained runs take 0.3 s — time the *disconnected* case at the guard, not the connected one (phase G M3).
25. **Uncapped adjacency lists in a paged item** (`connectedTo`, issue `handles` + every system name in the description): 200 × 6 handles = 64 KB at 10-char handles; measure the page with 8 neighbours, not 3 (phase G M4).

26. **Contact = connection, not a clash (phase H H1)**: `Evaluate(Intersects)` holds on a 0.5 mm boundary contact, so every beam end on a column face / pipe tee / end-to-end joint is a critical `hard_clash "touches"`; a frame or network checked against itself (the seed's own example) is all criticals. Probe a well-drawn frame and a tee'd main against themselves. Same family: containment by an *area* type (slab, room) is the normal state of a plan, not "lies inside" critical.
27. **Proper-only crossings + consecutive-pair pairing (phase H H2)**: `IntersectionPoints(proper: true)` drops a crossing at a route vertex on the face or through an outline vertex; the survivors then pair entry/exit wrongly and a boundary-inclusive "midpoint inside" test lets a chord *along the face* pass — passes vanish silently and phantom openings land between two real ones. Probe: vertex on the far face, through an outline vertex, two passes with one such vertex, start inside → out → in → out.
28. **"Nearest vertex" as the location of a gap (phase H M2)**: the closest pair of two segments has a vertex on one side and a *foot* on the other; midpoint-of-nearest-vertices sits metres from the gap on a long route. Take vertex + foot on the other shape.
29. **A pair cap that does not bound work (phase H M4)**: `MaxPairs 200 000` with an O(segA × segB) narrow phase and no segment-bounds culling = 5 ms per 64-vertex pair (17 min at the guard), 3 ms per 113-vertex arc pair; `ct` only per outer subject. Time the guard with tessellated arcs / 64-vertex polylines, not 2-vertex lines.
30. **Documented enum values that do not exist**: seed schema text named `MepEquipment` (real: `Equipment/Fixture/Terminal/Fitting`) — grep every type name in tool.json descriptions against `AecType.All`. Copy-pasted per-set text ("empty = every classified type") contradicting the engine defaults is the same class.

31. **State machines that keep undo state (phase I, 6/10)**: (a) a "live" cap with no exit for the finished-but-undoable state — `committed` counted against `MaxSets`, only `rollback` leaves it → the 21st commit deadlocks the drawing; (b) undo state released *before* the drawing confirms the undo held — `MarkRolledBack` disposed the snapshots even under a request `dryRun` or a per-handle `LAYER_LOCKED` failure (the commit side had `RevertToPending`, the rollback side had nothing); (c) a "did it stick?" verifier deciding from the first non-empty class with a fingerprint (layer / ColorIndex / XY extents / DBText text) blind to linetype, lineweight, style, dimStyle, hatch pattern, dynamic state, XLINE (`"?" == "?"`) → a real commit read as rolled back, snapshots dropped, re-commit double-applies `move`. Check every transition that disposes recovery data, and require all evidence classes to agree.
32. **Replay/commit tools re-raise the recorded call's problems as engine exceptions**: an atomic abort as `InvalidOperationException` counts against `commit_change_set`'s stability (only `Argument%Exception:` is excluded — `ToolRegistryDb.Runs.cs:62`); and the per-op warnings prefixed with `op N` defeat `Warn`'s de-duplication (200 ops × 3 = 111 KB). Group through `WarnItem`/`Settle`.

**Why:** the live harness scene is small and friendly (one attribute, unlocked attribute layers, no title blocks, no big xrefs) and asserts counts/measurements rather than layer/colour of what was created, so size, ordering and partial-commit defects pass 40–55/55 live and only surface by reading the write path against ARX semantics.

**How to apply:** for a read-only review, a scratchpad console app referencing `HPAutoCad.Aec/bin/Debug/net8.0-windows/*.dll` works without AutoCAD (needs `<PackageReference Include="System.Text.Json" Version="10.0.12"/>`; write files with the Write tool, Bash heredocs break on apostrophes; the scratchpad `probe/` from earlier sessions may still exist — Read then Write; a Python patch of Program.cs is the fastest edit). Run perf blocks with output redirected to a file (`| tail` hides everything until exit) and gate them behind an env var so the fast probes report first; start at a tenth of the guard and extrapolate. For envelope sizes a Python probe is faster. Check which ops/flags the harness never sent (`grep s.tool(`) — untested flags (`associative`, `dryRun` on non-create ops, `resolveStatus`, `dryRun` on `rollback_change_set`) are where the ARX-semantics bugs hide. Compare a replay table against the seed shims by hand (keys + defaults) — the test pins only the names.

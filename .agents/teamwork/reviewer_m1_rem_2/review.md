## 2. Verification of Remediation Items

### Item 1: Revit Framing Rebar Geometry Fix
- **Bottom Bar Elevation Formulation:**
  - Located in `HPKata.Revit/Services/FramingRebarGeometryCalculator.cs` (lines 21–27) and consumed in `FramingRebarGenerator.cs` (line 155):
    $$\Delta Z_{\text{bot}} = -H + c$$
    $$Z_{\text{bot}} = Z_0 - H + c$$
  - In a standard beam with $Z_0 = 3000\text{ mm}$, $H = 600\text{ mm}$, $c = 30\text{ mm}$:
    $$Z_{\text{top}} = 3000 - 30 = 2970\text{ mm}$$
    $$Z_{\text{bot}} = 3000 - 600 + 30 = 2430\text{ mm}$$
    $$\Delta Z = 540\text{ mm} = H - 2c$$
  - Both top and bottom rebar centerlines are strictly inside the host concrete envelope $[2400, 3000]\text{ mm}$. The previous defect (floating 30 mm above the top surface) is completely eliminated.
- **Multi-Bar Transverse Distribution:**
  - Located in `FramingRebarGeometryCalculator.CalculateTransverseOffsets` across clear width $w_{\text{clear}} = b - 2c$.
  - Generates symmetric transverse offsets:
    $$\text{offset}_i = -\frac{w_{\text{clear}}}{2} + i \cdot \frac{w_{\text{clear}}}{N - 1}, \quad i = 0, \dots, N-1$$
  - For $N = 1$, centered at $0.0$; for $N = 2$, at $\pm(b/2 - c)$; for $N = 3$, at $-120, 0, +120\text{ mm}$.
  - Bound in `FramingRebarGenerator.cs` to generate separate native `Rebar` elements for each transverse position across the beam width.
- **Stirrup Hoops Generation:**
  - Located in `FramingRebarGenerator.CreateStirrups` and `FramingRebarGeometryCalculator.CalculateStirrupCorners`.
  - Spacing stations along clear spans are dynamically generated by `BeamStirrupZoneCalculator.GenerateStirrupStations` based on $L/4$ dense support zones and midspan sparse zones.
  - Generates 4 closed planar rectangular segments: `[tl -> tr, tr -> br, br -> bl, bl -> tl]` with core dimensions $(b - 2c) \times (h - 2c)$.
  - Instantiated with `RebarStyle.StirrupTie` and orientation normal parallel to `beamDir`.

### Item 2: Revit Framing Analyzer Bidirectional Chaining
- **Bidirectional Expansion Algorithm:**
  - Located in `HPKata.Revit/Services/FramingChainCalculator.cs` and invoked by `RevitFramingAnalyzer.FindCollinearFramingChain`.
  - From the seed element:
    - `ExpandForward` grows forward from `chainEnd` toward the tail.
    - `ExpandBackward` grows backward from `chainStart` toward the head.
  - Allows the user to select any interior beam in a multi-span continuous line and accurately recovers the entire continuous line.
- **Reversed Curve Draw Orientations:**
  - Evaluates collinearity using absolute dot product:
    $$|\vec{u}_{\text{seed}} \cdot \vec{u}_{\text{cand}}| \ge \cos(\theta_{\text{tol}})$$
  - Correctly matches reversed beams ($\vec{u}_1 \cdot \vec{u}_2 \approx -1$) and checks distance from both endpoints ($P_0$ and $P_1$) against `chainEnd` and `chainStart`.

## 2. Logic Chain

1. **Authoritative Baseline Establishment**: By directly loading `C:\Dce Pro\AiAgent\DanhBa\danhba_lenh.json` and dumping the ECMA-335 `TypeDef` / `TypeRef` metadata tables from `C:\Dce Pro\DCE Pro.dll`, we established the immutable ground truth for all 311 commands, 11 Jigs, and 12 UI Forms without relying on memory or assumptions.
2. **Jig Token Derivation**: We verified that `TagLeader` (`0x02000E52`) through `DimNhanhMBKC` (`0x02000E5C`) form an exact 11-type contiguous block. TypeRef `0x01000024` maps directly to `Autodesk.AutoCAD.EditorInput.DrawJig`. Since no file in `HPDcePro.AutoCad` references `DrawJig` or implements these classes, all 11 Jigs are classified as `MISSING`.
3. **Form Token Derivation**: The 12 UI Forms map to WinForms (`Form`), WPF (`Window`), or AutoCAD native wrappers (`PaletteSet`, `IExtensionApplication`). In `HPDcePro.UI`, only 7 generic windows exist, none of which implement the specific inputs, controls, or algorithms of `DamCong_Frm`, `MongCoc_Frm`, or `TKT_frmMain`. Thus, all 12 are classified as `MISSING / MOCK`.
4. **311 Command Reconciliation**: By cross-referencing all 311 command names against the 80 `[CommandMethod]` attributes in `HPDcePro.AutoCad`:
   - 58 commands are implemented with authentic CAD drafting/geometry buffer logic.
   - 6 commands match the spec but are flagged as `ĐANG LÀ MOCK` due to hardcoded calls to sample methods.
   - 247 commands are completely absent from `HPDcePro.AutoCad` and classified as `MISSING`.
5. **Target Architecture Alignment**: Missing commands are assigned target implementation files in `HPDcePro.AutoCad/Commands/` following domain boundaries (Beam, Column, Slab, Footing, Rebar, AutoStr, Stair, Wall, EtabsSync, Drawing, GeneralCad).

## 3. Caveats

1. **Out-of-Catalog Commands**: 16 commands in `HPDcePro.AutoCad` are not in `danhba_lenh.json`. 10 of them originate from `DbimSteelAutocad.dll` (PEB steel framing commands), and 6 are synthetic wrappers (`AUTOSTR`, `COLUMNREC2`, `GANTRUCBLOCKDAM`, `IMPORTKICHTHUOC`, `UPDATETHEPTINHTOAN`, `XUATDULIEUMODELETABS`). These are valid extensions but tracked separately from the 311 core catalog.
2. **Duplicate Command Identifier**: `ChiaKhoangCach` is registered in both `RebarCommands.cs` and `SlabCommands.cs`. In AutoCAD, duplicate command method registrations cause an `AmbiguousMatchException` or runtime overwrite upon bundle loading. This must be refactored into a single command handler.
3. **Legacy WinForms vs. WPF Architecture**: 8 of the 12 legacy forms are legacy WinForms (`System.Windows.Forms.Form`). Per `PROJECT.md` and repository standards, they must be modernized into WPF `MahApps.Metro.Controls.MetroWindow` while preserving 100% parameter and calculation parity.

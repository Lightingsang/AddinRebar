## 2. ETABS & SAP2000 Beam Import Service (`HPKata.Core.Beams.Etabs`)

### 2.1 Ingestion Channels & Data Formats

The ETABS Beam Import Service supports three complementary ingestion channels:
1. **Clipboard / Delimited Text Parser (`EtabsTableParser`)**:
   - Parses tables copied directly from ETABS / SAP2000 "Display -> Show Tables" or exported `.txt` / `.tsv` / `.csv` files.
   - Automatically detects delimiters (tab `\t`, comma `,`, semicolon `;`, or multi-space).
   - Invariant culture number parsing handles both `.` and `,` decimal separators robustly.
2. **ClosedXML Excel Workbook Parser (`EtabsExcelImporter`)**:
   - Reads `.xlsx` files generated by ETABS batch report export.
   - Parses multiple sheets: `Story Definitions`, `Beam Object Connectivity`, `Concrete Beam Design`, `Frame Forces - Beams`.
3. **Live OAPI Data Provider Interface (`IEtabsDataProvider`)**:
   - Clean abstraction enabling direct connection to running ETABS 22 sessions via Named Pipe (`hpetabs-mcp-22`) or out-of-process COM (`ETABSv1.dll`).

### 2.3 Continuous Beam Assembly Algorithm (`EtabsContinuousBeamAssembler`)

In ETABS, a continuous beam across multiple bays is modeled as individual frame objects spanning between adjacent joint coordinates. The assembler automatically groups, chains, and verifies continuous beam runs:

1. **Partitioning by Story**:
   - Group all beam frame records by `Story` name and elevation.
2. **Collinear Vector Alignment**:
   - For each frame $i$ with endpoints $P_{1,i}(x_1, y_1, z_1)$ and $P_{2,i}(x_2, y_2, z_2)$:
     $$\vec{u}_i = \frac{P_{2,i} - P_{1,i}}{\|P_{2,i} - P_{1,i}\|}$$
   - Two spans $i$ and $j$ are candidate continuous spans if they share a common joint node (or within connection tolerance $\Delta \le 25\text{ mm}$) and their direction vectors satisfy:
     $$\vec{u}_i \cdot \vec{u}_j \ge \cos(1.0^\circ) \approx 0.99985$$
3. **Monotonic Axis Ordering**:
   - Sort the chained spans from left to right along the predominant beam axis:
     - If $|u_x| \ge |u_y|$: sort primarily by $X$ coordinate ($X_{\text{start}} < X_{\text{end}}$).
     - Otherwise: sort primarily by $Y$ coordinate ($Y_{\text{start}} < Y_{\text{end}}$).
4. **Support Identification & Sizing**:
   - Joints at the outer ends and intermediate span junctions are classified as supports.
   - Support widths are resolved from connecting column/wall dimensions if present in the model, or default to standard column widths ($300\text{ mm} - 400\text{ mm}$).
   - End supports without continuing frames are marked as `ExteriorSupport` (inducing standard $90^\circ$ anchor hooks); intermediate supports are marked as `InteriorSupport` (inducing continuous pass-through bars or $L/3$ cutoff splices).

## 3. TCVN 5574:2018 Rebar Auto-Selection Algorithm

### 3.1 Structural & Detailing Requirements (Clause 10.3)

1. **Area Fulfillment & Over-Design Clamping**:
   $$A_{s,\text{prov}} \ge A_{s,\text{req}} \quad \text{and} \quad \frac{A_{s,\text{prov}} - A_{s,\text{req}}}{A_{s,\text{req}}} \le \text{MaxWastePercent} \text{ (typically } 15\% - 20\%\text{)}$$
2. **Minimum Longitudinal Reinforcement Ratio**:
   $$\mu = \frac{A_{s,\text{prov}}}{b \cdot h_0} \ge \mu_{\min} = 0.10\%$$
   $$\mu \le \mu_{\max} = 3.0\% \quad (\text{Constructability and ductile failure limit})$$
3. **Continuous Corner Reinforcement**:
   - Every beam must have at least $2\Phi d$ continuous corner bars along the entire top and bottom edges to maintain the stirrup cage (minimum $\Phi 14$, recommended $\Phi 18 - \Phi 20$).
4. **Permissible Bar Diameter Pairings**:
   - Adjacent bars in the same layer must satisfy:
     $$|d_1 - d_2| \le 4\text{ mm} \quad (\text{e.g. } \Phi 20 + \Phi 18 \text{ OK; } \Phi 25 + \Phi 18 \text{ FORBIDDEN})$$
   - Symmetric placement is strictly enforced: larger diameter bars placed at the outer corners ($2\Phi d_1$) and smaller diameter bars placed in the interior ($m\Phi d_2$).
5. **Clear Horizontal Spacing Check (TCVN 5574:2018 Clause 10.3.1.2)**:
   - Clear beam width between stirrup inner faces:
     $$b_{\text{clear}} = b - 2(c + d_{sw})$$
     where $c = 25\text{ mm}$ (concrete cover) and $d_{sw} = 8\text{ mm}$ (stirrup diameter).
   - Clear horizontal gap between $n$ bars in a layer:
     $$t = \frac{b_{\text{clear}} - \sum_{i=1}^n d_i}{n - 1}$$
   - Lower bars (bottom tension):
     $$t \ge \max(25\text{ mm}, d_{\max})$$
   - Upper bars (top tension / pouring face):
     $$t \ge \max(30\text{ mm}, d_{\max})$$
6. **Multi-Layer Rules (Layer 2)**:
   - If Layer 1 spacing $t < t_{\text{req}}$, bars are split into 2 layers.
   - Layer 2 bars must be positioned directly in line with Layer 1 bars (vertically aligned) to preserve clear concrete vibration channels.
   - Vertical clear gap between Layer 1 and Layer 2:
     $$t_v \ge \max(25\text{ mm}, d_{\max}) \text{ (bottom)}; \quad t_v \ge \max(30\text{ mm}, d_{\max}) \text{ (top)}$$

### 3.2 Stirrup Auto-Selection Engine

1. **Leg Count Selection based on Beam Width $b$**:
   - $b \le 350\text{ mm}$: 2 legs ($1$ closed outer stirrup $\square$).
   - $350 < b \le 600\text{ mm}$: 4 legs ($1$ closed outer stirrup $\square + 2$ cross ties $\text{C}$, or $2$ overlapping closed stirrups).
   - $b > 600\text{ mm}$: 4 to 6 legs.
2. **Leg Spacing & Shear Capacity**:
   $$\left(\frac{A_v}{s}\right)_{\text{prov}} = \frac{n_{\text{leg}} \cdot \frac{\pi d_{sw}^2}{4}}{s} \ge \left(\frac{A_v}{s}\right)_{\text{req}}$$
   - Candidate diameters: $d_{sw} \in \{6, 8, 10, 12\}\text{ mm}$.
   - Support dense zone ($L/4$): candidate spacings $a100, a120, a150$.
   - Mid-span sparse zone ($L/2$): candidate spacings $a150, a200, a250$, clamped to $\min(0.75h, 500\text{ mm})$ per TCVN code.

### 3.3 Side/Skin Reinforcement (`thep_gia`)

- Per TCVN 5574:2018 Clause 10.3.1.5: When beam depth $h > 700\text{ mm}$, side face longitudinal bars are mandatory.
- Maximum vertical spacing between side bars: $s_w \le 400\text{ mm}$.
- Required number of side bar pairs:
  $$n_{\text{side,pairs}} = \max\left(1, \left\lceil \frac{h - 2c - 100}{400} \right\rceil - 1\right)$$
- Standard side bar diameter: $\Phi 12$ or $\Phi 14$.

### 3.4 Rebar Candidate Ranking & Selection Metric

Each compliant candidate is evaluated by an optimization score (lower is better):
$$\text{Score} = \text{WasteRatioPercent} + P_{\text{layer}} + P_{\text{dia}} + P_{\text{count}}$$
where:
- $\text{WasteRatioPercent} = \frac{A_{s,\text{prov}} - A_{s,\text{req}}}{A_{s,\text{req}}} \times 100\%$.
- $P_{\text{layer}} = +25.0$ if 2 layers (strong preference for single layer for ease of pouring).
- $P_{\text{dia}} = -5.0$ if bar diameter is standard jobsite size ($18, 20, 22\text{ mm}$); $+10.0$ for non-preferred sizes ($14, 28, 32\text{ mm}$).
- $P_{\text{count}} = +3.0 \times (n - 2)$ (prefers fewer larger bars over many small bars to maximize clear spacing).

## 4. WPF UI Architecture (`HPKata.UI`)

### 4.1 `BeamDetailingViewModel` & `BeamDetailingView`

`BeamDetailingView` serves as the primary visual editor for continuous beams, supporting both standard design detailing (`ve_dam`) and shop fabrication drawing (`ve_dam_shop`).

#### Structure & Data Binding:
1. **Header Panel**:
   - `BeamMark` (`string`, e.g. "D1"), `StoryName` (`string`, e.g. "Tầng 2").
   - `ConcreteGrade` (`string`, e.g. "B25"), `MainSteelGrade` (`string`, e.g. "CB400-V"), `StirrupSteelGrade` (`string`, e.g. "CB240-T").
   - `ConcreteCoverMm` (`double`, default 25 mm).
   - `DetailingMode` (`enum`: `DesignDetailing` vs `ShopDrawing11_7m`).
2. **Span Configuration DataGrid**:
   - Bound to `ObservableCollection<BeamSpanViewModel> Spans`.
   - Columns: Span Index, Span Length ($L_n$), Width ($b$), Depth ($h$), Left Support Width, Right Support Width, Cantilever indicators.
3. **Support & Midspan Reinforcement Inputs**:
   - **Top Reinforcement**:
     - Continuous top bars: `TopContinuousCount`, `TopContinuousDiameter` (e.g. `2d18`).
     - Support top extra bars (Left, Support 2, Support 3, Right):
       - Layer 1 extra: Count, Diameter, Cutoff ratio (default $L/4$ or $L/3$).
       - Layer 2 extra: Count, Diameter, Cutoff ratio (default $L/4 - 100\text{ mm}$).
   - **Bottom Reinforcement**:
     - Continuous bottom bars: `BotContinuousCount`, `BotContinuousDiameter` (e.g. `2d18`).
     - Midspan bottom extra bars:
       - Layer 1 extra: Count, Diameter, Start offset ($0.1L$), End offset ($0.9L$).
       - Layer 2 extra: Count, Diameter.
   - **Side / Skin Bars**:
     - `HasSideBars` (Auto-enabled when $h > 700\text{ mm}$).
     - `SideBarCountPerFace`, `SideBarDiameter` (e.g. $2 \times 2\Phi 12$).
4. **Stirrups & Intersections Panel**:
   - `StirrupDiameter` ($\Phi 6, \Phi 8, \Phi 10$), `LegCount` (2, 4).
   - `DenseSpacing` (e.g. $a100, a150$), `DenseRatio` ($0.25L$).
   - `SparseSpacing` (e.g. $a150, a200$).
   - `HangerStirrupConfig`: Secondary beam suspension stirrups ($5\Phi 10a50$) and anti-crack corner diagonal bars ($2\Phi 14$).
5. **Interactive 2D Canvas Preview**:
   - Renders longitudinal elevation profile, supports, rebar curtailment lines, stirrup zones, and cross-section cuts.
   - Distinct brush colors for Top Bars (Red/Orange), Bottom Bars (Blue/Cyan), Stirrups (Magenta), and Concrete Outline (Gray).
6. **Action Commands**:
   - `[RelayCommand] SaveBeam()`: Serializes beam specification to DWG XRecord or project dictionary.
   - `[RelayCommand] DrawCadBeam()`: Invokes `ve_dam` or `ve_dam_shop` in active AutoCAD document.
   - `[RelayCommand] CreateRevitRebar()`: Generates native 3D `Rebar` elements in host `Structural Framing`.

### 4.2 `EtabsImportViewModel` & `EtabsImportView`

`EtabsImportView` manages batch importing, story filtering, rebar auto-selection, and multi-beam generation.

#### Structure & Data Binding:

   - File Path picker with OpenFileDialog for `.xlsx` or `.txt`.

   - `PreferredDiameters`: Toggle buttons for $\Phi 16, \Phi 18, \Phi 20, \Phi 22, \Phi 25$.
   - `MaxAllowableWaste`: Slider from $5\%$ to $30\%$ (default $15\%$).
   - `MaxLayers`: 1 layer preferred, max 2 layers.
3. **Imported Continuous Beams Grid**:
   - Bound to `ObservableCollection<EtabsBeamRowViewModel> Beams`.
   - Columns:
     - `IsSelected` (Checkbox)
     - `StoryName`
     - `RunName` (e.g. "D1 (3 nhịp)")
     - `Dimensions` (e.g. "250x500")
     - `TotalLength` (e.g. "14.5 m")
     - `TopRebarSummary` (e.g. "Gối: 2d20 + 2d18 | Nhịp: 2d18")

     - `StirrupSummary` (e.g. "d8a100/a200 (2 nhánh)")
     - `StatusBadge`: Green (Compliant), Yellow (Over-reinforced / 2 layers), Red (Unsatisfied).
4. **Action Commands**:
   - `[RelayCommand] RunAutoSelection()`: Executes `TcvnRebarAutoSelector` across all selected beams.
   - `[RelayCommand] OpenDetailingView()`: Opens selected beam in `BeamDetailingView` for granular manual edits.
   - `[RelayCommand] BatchDrawCad()`: Dispatches batch drafting `vda` / `vdas` into AutoCAD.
   - `[RelayCommand] BatchGenerateRevit()`: Generates native Rebars for all matching Revit beams.

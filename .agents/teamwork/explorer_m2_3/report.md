## 1. Executive Summary

This investigation analyzes four critical resilience and integrity mechanisms in the HPBim pipeline:
1. **Ledger Hydration across Process Restarts**: Ensuring `BimCoordinationLedgerService.LoadFromFile` / `LoadFromFileAsync` completely hydrates the `_mappings` dictionary (`CompositeSourceKey` → `TargetUniqueId`) from serialized disk state, including canonical string normalization and element-level fallback hydration.
2. **Intent Journal Metadata Preservation on Cache Miss**: Rectifying `IntentJournal.UpdateStatusAsync` which currently synthesizes a blank `IntentJournalRecord` on in-memory cache misses (such as after process restart/crash recovery), wiping out 100% of vital metadata (`PlanHash`, `ItemCount`, `TargetDoc`, `TargetDocId`).
3. **Atomic File Replace & File-Locking in Ledger Serializer**: Upgrading `BimCoordinationLedgerSerializer` from naive `File.WriteAllText` / `StreamWriter` truncation to an atomic `.tmp` file write with hardware disk flush and Windows filesystem replacement (`File.Move(..., overwrite: true)`), wrapped in an inter-process file-locking protocol to eliminate race conditions and corruption upon sudden process termination.
4. **3-Factor Reconcile Verification & `OutcomeUnknown` Preservation**: Hardening `ReconcileService` to require simultaneous matching of all 3 identity factors (`OperationId`, `PlanHash`, `TargetDocId`) before acknowledging `Committed`. Critically, eliminating the faulty assumption where missing receipts were treated as `RolledBack` / `Failed`, and strictly preserving `OutcomeUnknown` (`StillUnknown`) to prevent dangerous blind retries and model overwrites.

#### 1.2 Identified Failure Modes
1. **Unsynchronized `_ledger` State**: `ApplyLoadedLedger` assigns `_ledger = loaded;` before populating `_mappings`. If `_mappings` is later queried or if `SyncLedgerState()` is not explicitly called, `_ledger.Mappings` may be detached from `_mappings`.
2. **Key Format Discrepancies**: In `CompositeSourceKey`, the canonical string format is `[Doc]#[Category]:PrimaryHandle` (`ToString()`), while plain format is `Doc#Category:PrimaryHandle` (`PlainKey`). 3. **Empty SourceKey in Deserialized Mappings**: If `LedgerElementMapping` in JSON lacks a `sourceKey` field or has empty string, `kvp.Value.SourceKey` becomes `CompositeSourceKey.Empty`. When callers query using a valid `CompositeSourceKey`, equality fails.
4. **Missing Fallback Hydration from `Elements`**: If a ledger JSON was generated by earlier phases or has elements in Step 3+ with valid `RevitTargetSpec.UniqueId` but the `mappings` section was omitted or partial, `_mappings` remains empty, forcing unnecessary re-creations.

#### 1.3 Recommended Strategy
Implement a dedicated `HydrateMappings(BimCoordinationLedger loaded)` method in `BimCoordinationLedgerService.Mappings.cs`:
- Iterate `loaded.Mappings`: parse canonical and plain representations using `CompositeSourceKey.TryParse(kvp.Key, out var key, allowEmptyDoc: true)`. Ensure `mapping.SourceKey` is populated. Register under both `key.ToString()` and `key.PlainKey`.
- Iterate `loaded.Elements`: for any element having `RevitTargetSpec?.UniqueId` not yet present in `_mappings`, derive the `CompositeSourceKey` from `(DwgSheet, Category, Handle)` and register the mapping.
- Call `SyncLedgerState()` at the conclusion of `ApplyLoadedLedger`.

### Item 2: `IntentJournal.UpdateStatusAsync` Metadata Preservation on Cache Miss

#### 2.1 Direct Observations
- **File**: `HPBim/src/HPBim.Client/Connection/IntentJournal.cs` (lines 49-70)
- **File**: `HPBim/src/HPBim.Client/Connection/IntentJournalRecord.cs` (lines 12-42)

```csharp
// Current implementation in IntentJournal.cs:
public async Task UpdateStatusAsync(
    Guid operationId,
    IntentStatus status,
    string? errorReason = null,
    CancellationToken cancellationToken = default)
{
    ThrowIfDisposed();

    var updated = _activeRecords.TryGetValue(operationId, out var existing)
        ? existing with { Status = status, TimestampUtc = DateTime.UtcNow, ErrorReason = errorReason }
        : new IntentJournalRecord
        {
            OperationId = operationId,
            Status = status,
            TimestampUtc = DateTime.UtcNow,
            ErrorReason = errorReason
        };

    _activeRecords[operationId] = updated;
    string jsonLine = JsonSerializer.Serialize(updated, JsonOptions);
    await AppendLineWithFlushAsync(jsonLine, cancellationToken).ConfigureAwait(false);
}
```

#### 2.2 Identified Failure Modes
1. When a process restarts or crashes after dispatching an in-flight operation, a new `IntentJournal` instance is constructed. `_activeRecords` (an in-memory `ConcurrentDictionary`) is initially **EMPTY**.
2. When the recovery loop or CLI triggers `UpdateStatusAsync(operationId, IntentStatus.OutcomeUnknown, ...)`, `_activeRecords.TryGetValue` returns `false` (cache miss).
3. The method falls back to `new IntentJournalRecord { OperationId = operationId, Status = status, ... }`.
4. As a result:
   - `PlanHash` reverts to `""` (empty string).
   - `ItemCount` reverts to `0`.
   - `TargetDoc` reverts to `new DocumentIdentitySnapshot()` (empty title, empty GUID).
5. When `ReconcileService` reads this updated record from the journal, **the plan hash and document snapshot are completely destroyed**, making 3-factor reconciliation impossible across process restarts!

#### 2.3 Recommended Strategy
On cache miss in `UpdateStatusAsync`, asynchronously reload the latest record map from the journal file on disk via `ReadLatestRecordsMapAsync(cancellationToken)` before constructing the updated record:
```csharp
if (!_activeRecords.TryGetValue(operationId, out var existing))
{
    var diskRecords = await ReadLatestRecordsMapAsync(cancellationToken).ConfigureAwait(false);
    if (diskRecords.TryGetValue(operationId, out var diskRecord))
    {
        existing = diskRecord;
    }
}
```
If found on disk, execute `existing with { Status = status, TimestampUtc = DateTime.UtcNow, ErrorReason = errorReason }`, which preserves 100% of all metadata fields.

### Item 3: `BimCoordinationLedgerSerializer` Atomic File Replace & File-Lock

#### 3.1 Direct Observations
- **File**: `HPBim/src/HPBim.Core/Coordination/BimCoordinationLedgerSerializer.cs` (lines 56-108)

```csharp
    if (!string.IsNullOrEmpty(dir) && !Directory.Exists(dir))

    }
```

#### 3.2 Identified Failure Modes
1. `File.WriteAllText(filePath, json)` immediately truncates the existing file to 0 bytes before writing. If the process terminates, loses power, or crashes mid-write, the target file is left in an unparseable, corrupt, or empty state.
2. No file locking exists. Multiple CLI processes or background tasks attempting to save the ledger simultaneously will collide, causing `IOException: The process cannot access the file because it is being used by another process`.
3. Read operations (`DeserializeFromFile`) have no retry logic during transient write/move operations, leading to spurious read crashes.

#### 3.3 Recommended Strategy
1. **Atomic File Replace (.tmp -> atomic replace)**:
   - Construct a temporary file in the same directory: `${filePath}.tmp_{Guid.NewGuid():N}`.
   - Write the JSON to the temporary file using `FileStream` (`FileMode.CreateNew`, `FileAccess.Write`, `FileShare.None`).
   - Call `stream.Flush(flushToDisk: true)` to ensure hardware persistence.
   - Execute `File.Move(tempPath, filePath, overwrite: true)` (utilizing Windows kernel `MoveFileEx` atomic replacement).
   - In a `finally` block, ensure any uncommitted temporary file is deleted if an error occurred.
2. **File Lock**:
   - Establish an inter-process file lock via a companion `${filePath}.lock` file opened with `FileShare.None`.
   - Incorporate exponential backoff/polling (up to 5 seconds timeout) so concurrent writers queue gracefully.
3. **Resilient Reader**:
   - In `DeserializeFromFile` and `DeserializeFromFileAsync`, wrap read attempts in a short retry loop (up to 3 seconds with 20ms delay) to withstand momentary file moves.

```csharp
    public LedgerElementMapping RegisterMapping(LedgerElementMapping mapping)
    {
        if (mapping == null) throw new ArgumentNullException(nameof(mapping));
        string canonicalKey = mapping.SourceKey.ToString();
        _mappings[canonicalKey] = mapping;
        if (!string.Equals(canonicalKey, mapping.SourceKey.PlainKey, StringComparison.OrdinalIgnoreCase))
        {
            _mappings[mapping.SourceKey.PlainKey] = mapping;
        }
        _ledger = _ledger.RegisterMapping(mapping);
        return mapping;

        CompositeSourceKey key,
        string uniqueId,
        string planHash,
        ElementExecutionStatus status,
        long? elementId = null)
    {
        if (key == null) throw new ArgumentNullException(nameof(key));
        string keyStr = key.ToString();

        if (_mappings.TryGetValue(keyStr, out var existing))
        {
            var updated = existing.WithUpdate(uniqueId, elementId, planHash, status);
            _mappings[keyStr] = updated;
            _mappings[key.PlainKey] = updated;
            _ledger = _ledger.RegisterMapping(updated);
            return updated;
        }

        var created = LedgerElementMapping.Create(key, uniqueId, elementId, key.Category, key.PrimaryHandle, planHash);
        _mappings[keyStr] = created;
        _mappings[key.PlainKey] = created;
        _ledger = _ledger.RegisterMapping(created);
        return created;
    }

    public bool RemoveMapping(CompositeSourceKey key)
    {
        if (key == null) throw new ArgumentNullException(nameof(key));
        bool removed = _mappings.Remove(key.ToString());
        _mappings.Remove(key.PlainKey);
        if (removed)
        {
            _ledger = _ledger.RemoveMapping(key);
        }
        return removed;
    }

    public void SyncFromExecutionRecords(IEnumerable<ElementExecutionRecord> records, string planHash)
    {
        if (records == null) return;
        foreach (var rec in records)
        {
            if (rec.Status is ElementExecutionStatus.Created or ElementExecutionStatus.Updated)
            {
                if (!string.IsNullOrEmpty(rec.TargetUniqueId))

                    UpdateMapping(rec.SourceKey, rec.TargetUniqueId!, planHash, rec.Status, rec.TargetElementId);

                        LastModifiedStatus = ElementExecutionStatus.NoOp

                    _mappings[rec.SourceKey.PlainKey] = noopUpdated;
                    _ledger = _ledger.RegisterMapping(noopUpdated);
                }
            }
        }

    public void HydrateMappings(BimCoordinationLedger loaded)
    {
        if (loaded == null) return;

        if (loaded.Mappings != null)
        {
            foreach (var kvp in loaded.Mappings)

                if (kvp.Value == null) continue;
                var mapping = kvp.Value;
                if (mapping.SourceKey == null || mapping.SourceKey == CompositeSourceKey.Empty)

                    : kvp.Key;

                _mappings[canonical] = mapping;
                if (mapping.SourceKey != null)
                {
                    _mappings[mapping.SourceKey.PlainKey] = mapping;
                }
            }
        }

        if (loaded.Elements != null)

            foreach (var el in loaded.Elements)
            {
                if (el.RevitTargetSpec == null || string.IsNullOrWhiteSpace(el.RevitTargetSpec.UniqueId)) continue;

                string handle = el.CadSourceSpec?.Handle ?? el.Id;
                var key = new CompositeSourceKey(docId, el.Category, handle);
                if (!_mappings.ContainsKey(key.ToString()))

                        key, el.RevitTargetSpec.UniqueId, el.RevitTargetSpec.ElementId, el.Category, el.Code ?? el.Id, string.Empty);
                    _mappings[key.ToString()] = mapping;
                    _mappings[key.PlainKey] = mapping;
                }
            }
        }
    }
```

```csharp
    private static string ReadFileWithRetry(string filePath, int timeoutMs)
```

```csharp
namespace HPBim.Client.Recovery;

using System;
using System.Collections.Generic;
using System.IO;
using System.Threading;
using System.Threading.Tasks;
using HPBim.Client.Connection;
using HPBim.Core.Coordination;
using HPBim.Core.Execution;

public sealed class ReconcileService : IReconcileService
{
    private readonly IIntentJournal _journal;
    private readonly IRevitPipeClient _pipeClient;
    private readonly BimCoordinationLedgerService _ledgerService;
    private readonly IExtensibleStorageReceiptReader _receiptReader;

    public ReconcileService(
        IIntentJournal journal,
        IRevitPipeClient pipeClient,
        BimCoordinationLedgerService ledgerService,
        IExtensibleStorageReceiptReader? receiptReader = null)
    {
        _journal = journal ?? throw new ArgumentNullException(nameof(journal));
        _pipeClient = pipeClient ?? throw new ArgumentNullException(nameof(pipeClient));
        _ledgerService = ledgerService ?? throw new ArgumentNullException(nameof(ledgerService));
        _receiptReader = receiptReader ?? new ExtensibleStorageReceiptReader(pipeClient);
    }

    public async Task<IReadOnlyList<ReconcileResult>> ReconcileAllUnknownIntentsAsync(CancellationToken cancellationToken = default)
    {
        var unresolved = await _journal.GetIncompleteIntentsAsync(cancellationToken).ConfigureAwait(false);
        if (unresolved.Count == 0)
        {
            return new[] { ReconcileResult.NoOp() };
        }

        var results = new List<ReconcileResult>(unresolved.Count);
        foreach (var intent in unresolved)
        {
            var res = await ReconcileSingleIntentAsync(intent, cancellationToken).ConfigureAwait(false);
            results.Add(res);
        }

        return results;
    }

    public async Task<ReconcileResult> ReconcileIntentAsync(Guid operationId, CancellationToken cancellationToken = default)
    {
        var intent = await _journal.GetIntentAsync(operationId, cancellationToken).ConfigureAwait(false);
        if (intent == null)
        {
            return ReconcileResult.StillUnknown(operationId, string.Empty, "Intent not found in journal.");
        }

        return await ReconcileSingleIntentAsync(intent, cancellationToken).ConfigureAwait(false);
    }

    private async Task<ReconcileResult> ReconcileSingleIntentAsync(IntentJournalRecord intent, CancellationToken ct)
    {
        try
        {
            if (!_pipeClient.IsConnected)
            {
                await _pipeClient.ConnectAsync(ct).ConfigureAwait(false);
            }

            var receipt = await _receiptReader.FindReceiptAsync(intent.OperationId, intent.PlanHash, ct).ConfigureAwait(false);
            if (receipt != null && VerifyThreeFactors(intent, receipt))
            {
                return await ApplyCommittedReceiptAsync(intent, receipt, ct).ConfigureAwait(false);
            }

            string reason = receipt == null
                ? "Receipt absent in Revit Extensible Storage. Preserving OutcomeUnknown to prevent blind overwrite."
                : $"3-Factor verification mismatch: OperationId match={receipt.OperationId == intent.OperationId}, PlanHash match={string.Equals(receipt.PlanHash, intent.PlanHash, StringComparison.OrdinalIgnoreCase)}, TargetDocId match={MatchTargetDocId(intent, receipt)}. Preserving OutcomeUnknown.";

            await _journal.UpdateStatusAsync(intent.OperationId, IntentStatus.OutcomeUnknown, reason, ct).ConfigureAwait(false);
            return ReconcileResult.StillUnknown(intent.OperationId, intent.PlanHash, reason);
        }
        catch (Exception ex) when (ex is RevitPipeException or IOException or TimeoutException)
        {
            return ReconcileResult.StillUnknown(intent.OperationId, intent.PlanHash, $"Pipe communication error during reconciliation: {ex.Message}");
        }
    }

    public static bool VerifyThreeFactors(IntentJournalRecord intent, CoordinationReceiptRecord receipt)
    {
        if (intent == null || receipt == null) return false;

        bool factor1OpId = intent.OperationId != Guid.Empty && receipt.OperationId == intent.OperationId;
        bool factor2PlanHash = !string.IsNullOrEmpty(intent.PlanHash) &&
                               !string.IsNullOrEmpty(receipt.PlanHash) &&
                               string.Equals(intent.PlanHash, receipt.PlanHash, StringComparison.OrdinalIgnoreCase);
        bool factor3TargetDocId = MatchTargetDocId(intent, receipt);

        return factor1OpId && factor2PlanHash && factor3TargetDocId;
    }

    private static bool MatchTargetDocId(IntentJournalRecord intent, CoordinationReceiptRecord receipt)
    {
        string expectedDocId = intent.TargetDocId;
        string actualDocId = receipt.TargetDocId;

        if (string.IsNullOrWhiteSpace(expectedDocId) && string.IsNullOrWhiteSpace(actualDocId))
        {
            return true;
        }

        if (string.IsNullOrWhiteSpace(expectedDocId) || string.IsNullOrWhiteSpace(actualDocId))
        {
            return false;
        }

        if (string.Equals(expectedDocId, actualDocId, StringComparison.OrdinalIgnoreCase))
        {
            return true;
        }

        var targetDoc = intent.TargetDoc;
        if (targetDoc != null && !targetDoc.IsEmpty)
        {
            if (!string.IsNullOrEmpty(targetDoc.Title) &&
                string.Equals(targetDoc.Title, actualDocId, StringComparison.OrdinalIgnoreCase))
            {
                return true;
            }

            if (targetDoc.VersionGuid != Guid.Empty &&
                Guid.TryParse(actualDocId, out var parsedVer) &&
                targetDoc.VersionGuid == parsedVer)
            {
                return true;
            }

            if (targetDoc.CentralGuid.HasValue &&
                Guid.TryParse(actualDocId, out var parsedCentral) &&
                targetDoc.CentralGuid.Value == parsedCentral)
            {
                return true;
            }

            if (!string.IsNullOrEmpty(targetDoc.PathName) &&
                string.Equals(targetDoc.PathName, actualDocId, StringComparison.OrdinalIgnoreCase))
            {
                return true;
            }
        }

        return false;
    }

    private async Task<ReconcileResult> ApplyCommittedReceiptAsync(
        IntentJournalRecord intent,
        CoordinationReceiptRecord receipt,
        CancellationToken ct)
    {
        var mappings = receipt.ElementMap ?? new Dictionary<string, string>();
        foreach (var (keyStr, uniqueId) in mappings)
        {
            if (CompositeSourceKey.TryParse(keyStr, out var sourceKey) && sourceKey != null)
            {
                _ledgerService.UpdateMapping(sourceKey, uniqueId, intent.PlanHash, ElementExecutionStatus.Created);
            }
        }

        await _journal.UpdateStatusAsync(intent.OperationId, IntentStatus.Committed, null, ct).ConfigureAwait(false);
        return ReconcileResult.Committed(intent.OperationId, intent.PlanHash, mappings);
    }
}
```

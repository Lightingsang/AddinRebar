# Troubleshooting — symptom → cause → what to do

| Symptom | Cause | Do |
|---|---|---|
| Tool list is empty / server missing in Claude Code | `.mcp.json` has no `hprebar-revit` entry, or the exe path is wrong | user adds the entry (exe `HPRebar/output/HPRebar.Mcp.Server/HPRebar.Mcp.Server.exe`, env `HPREBAR_MCP_Bridge__RevitVersion=2026`); never commit `.mcp.json` |
| Server starts but a seed is missing / behaves like an old version | an old published exe (seeds are embedded and installed on first start; upgraded only while `_seeds.json` proves the user never edited them) | republish: `dotnet publish HPRebar/HPRebar.Mcp.Server -c Release -r win-x64 -p:PublishSingleFile=true -p:SelfContained=false -o HPRebar/output/HPRebar.Mcp.Server`; the exe is locked while any Claude Code session runs it — rename the running exe (NTFS allows it), publish into the path, restart the sessions. An edited seed is never overwritten: `HPRebar.Mcp.Server.exe registry show <name>` and compare |
| Every call: "bridge not connected" / pipe `hprebar-mcp-r2026` missing | Revit closed, add-in not loaded, or listener stopped | start Revit 2026; check `%AppData%\Autodesk\Revit\Addins\2026\HPRebar.McpBridge.addin` + folder `HPRebar.McpBridge\` exist (`dotnet build HPRebar/HPRebar.slnx -c Debug.R26` with Revit closed deploys them); answer *Always Load* to "publisher could not be verified"; ribbon **HPRebar ▸ MCP ▸ MCP Bridge** → *Start listener* |
| Bridge window says the bridge did not initialise | exception at Revit start (Roslyn not resolved, ALC clash) | read `%LocalAppData%\HPRebar\McpBridge\logs\mcpbridge-<date>.log`; a healthy start logs `MCP bridge ready on pipe hprebar-mcp-r2026` then `MCP scripting self-check OK in … ms: revit 2026, doc: …` |
| `-32001` "Allow AI code execution" | opt-in off (resets on every Revit start, never persisted) | user ticks **Allow AI code execution in this Revit session** in the bridge window; no MCP way to turn it on |
| `-32002` "Another script is still running in Revit" | one script at a time; the previous one has not returned | wait; `cancel_execution` stops a cooperative script at its next `ct` check |
| `isError` "No document is open in Revit. Open a project first." | Revit shows the start page or only a family | open a project (this is a run result, not a JSON-RPC `-32003`) |
| "Revit already has a transaction open (a command is in progress). Finish it and retry." | `get_revit_context.isModifiable: true` — the user is inside a command, sketch or edit mode | user clicks Finish/Cancel in Revit; read-only (`none`) runs are unaffected |
| "The active document is read-only; only transaction=\"none\" scripts can run." | detached/read-only model | open a writable copy, or stay read-only |
| "The active document is a family; modifying families is disabled in the bridge settings." | `AllowFamilyDocuments` is off by default | read-only runs work; do not suggest editing `settings.json` — ask the user whether they really want scripted family edits |
| "Revit refused the request (…): it is in a modal dialog or another command." | `ExternalEvent.Raise` was not accepted | user closes the dialog; retry |
| `diagnostics[{id: "GUARD"…}]` "is not allowed in Revit scripts" | denied namespace / identifier / member (`System.IO`, `File`, `Task`, `.GetProperty`, `Expression`, `#r`) | see `script-contract.md`; use a seed or restructure; `System.IO.Path` is allowed |
| `diagnostics[{id: "CS0246"…}]` "type or namespace … could not be found" | namespace outside the defaults (`Room` is in `Autodesk.Revit.DB.Architecture`) | full name or a `using` at the top of the script |
| `diagnostics[{id: "CS1503"…}]` around `ElementId` / `int` | `new ElementId(int)` overload vs long, or `IntegerValue` | `new ElementId(args.Long("id"))`, `id.Value` |
| "The script modified the model without a transaction." | `transaction: "none"` with a write | `transaction: "auto"` (or `manual` with the script's own `Transaction`) |
| "The script left a Transaction open." | `manual` without `Commit`/`RollBack` on every path | `using (var t = new Transaction(doc, "…")) { t.Start(); …; t.Commit(); }` |
| "Revit rejected the change (a failure was posted during commit)." | a Revit **error** (not a warning) at commit: invalid geometry, unjoinable elements, constraint conflict | read `logs`; fix the input (closed loop, valid host, element on the level); do not retry unchanged |
| `Autodesk.Revit.Exceptions.ArgumentException` from a `Create` call | feet/mm mix-up (a 3000-foot wall), degenerate curve, wrong level | convert with `UnitUtils`; check the points in `logs` before creating |
| Seed warns "typeId … is not a … type — used …" | the id belongs to another category | take the id from `get_available_family_types {categoryList: [...]}` of that category |
| `create_point_based_element` door/window: "no wall within 1500 mm" | the point is not on a wall | pass `hostWallId`, or move the point onto the wall's location line |
| `create_room` returns `enclosed: false` | walls do not close around the point, or no room-bounding elements on that level | check with `ai_element_filter {filterCategory: "OST_Walls", filterVisibleInCurrentView: true}`; Revit places the room anyway (area 0) |
| `tag_all_walls` in a 3D view: Revit error "3D view … is not locked" | tags need a plan/section/locked 3D view | activate a plan view (user) — the tool takes the active view |
| `create_dimensions` answers "pass elementIds" | auto-detect ran in a 3D view or found nothing at the points | pass `elementIds` (grids/walls/columns), or activate a plan |
| `timedOut: true` | more than `timeoutSeconds` (default 30, max 120); a timed-out run never commits even if it returned | do less per call (`Take`, one level at a time), raise the timeout up to 120 |
| `truncated: true` | `value` > 64 KB | return counts + `Take(n)`; page with an `offset` in `args` |
| `changed` = 0 after a real run that should have written | the script returned before writing, or wrote to a view/selection only | read `logs`; verify with a read script — `changed` is what `DocumentChanged` reported |
| `rolledBack: true` without `dryRun` | exception after writes, timeout, or Revit rejected the commit | the run failed as a whole; read `message`/`diagnostics`; never re-run blindly |
| `run_tool` refuses a published tool: "quarantined" | ≥ 5 runs with > 40 % failures (argument errors excluded) | fix and `propose_tool {newVersion: true}` → test → publish → CLI approve, or `manage_tool {action: "restore"}` |
| `search_tools` finds nothing in Vietnamese | FTS ranks on description/tags; short Vietnamese tokens may miss | try English keywords (`wall`, `room`, `level`, `mark`) or `search_tools {query: null, category: "Data"}` to list a category |
| Second Revit instance: bridge window says pipe in use | one bridge per pipe per version | the first instance keeps serving; close the second or use it without MCP |
| Another MCP add-in (`mcp-servers-for-revit`, `revit_mcp_plugin`, Dynamo, RevitPythonShell) is loaded too | HPRebar's bridge runs in its own load context; Roslyn coexistence with those is **not verified** | if scripts fail to compile only when the other add-in is loaded, read the bridge log first, then report — do not uninstall other add-ins on your own |
| Bridge deploy fails: DLL locked | Revit is running | close Revit before `dotnet build … -c Debug.R26`; use `-p:DeployAddin=false` for compile checks |

Paths: bridge log `%LocalAppData%\HPRebar\McpBridge\logs\`, bridge settings + audit `%AppData%\HPRebar\McpBridge\` (`settings.json` holds `AutoStartListener` only — the opt-in is never persisted; `audit\audit-YYYYMMDD.log` one JSON line per run), registry `%AppData%\HPRebar\McpServer\` (`registry.db` SQLite + `tools-library\<Category>\<name>\{tool.json, code.cs, examples.json}`, `_review\`, `_seeds.json`; relocate with `HPREBAR_MCP_Registry__LibraryPath` / `__DbPath`).

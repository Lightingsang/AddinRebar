TRỤ CỘT 1 Thuật toán Cốt thép Dầm Kata (Sheet Dam & 3D Math)

▤ Ma trận ô tính cốt lõi trong Sheet Dam

Kata lưu trữ dữ liệu dưới dạng bảng tính ma trận 2D được chuẩn hóa:

📐 Công thức Hình học Không gian 3D

Tọa độ cục bộ dầm: trục $\vec{X}$ dọc dầm, $\vec{Y}$ ngang dầm, $\vec{Z}$ thẳng đứng.

Cao độ lớp thép chủ trên ($Z_{top}$): $$Z_{top} = -cover - d_{stirrup} - \frac{d_{main}}{2}$$
Chiều dài móc bẻ neo 90° tại cột biên: $$L_{hook\_top} = h - cover_{top} - cover_{bot} - 2 d_{stirrup}$$
Khoảng rải thép chủ theo phương ngang ($Y_i$): $$Y_i = -\frac{b}{2} + cover + d_{stirrup} + \frac{d_{main}}{2} + i \times \Delta Y$$ với $\Delta Y = \frac{b - 2(cover + d_{stirrup} + d_{main}/2)}{n_{bars} - 1}$.

TRỤ CỘT 2 Quy chuẩn Bố trí & Thư viện Uốn Thép dangthep (Update2025)

🎨 Giải mã Bảng Mã Hình Dạng Uốn (DangThep Catalog)

Mã 00 Thanh thẳng
────────────── A ──────────────

Thép nhịp gia cường, cốt sườn dầm. $L = A$.

Mã 05a / 15a Móc L 90°
│ B
└──────────── A ────────────

Thép chủ neo cột biên, thép gối biên. $L = A + B$.

Mã 41 Đai kín chữ nhật
┌─── A ───┐
│          │ B (Móc 135°)
└─── A ───┘

Đai chịu cắt chính bao quanh dầm. $L = 2(A+B) + \text{hooks}$.

Mã 45 / 45a Đai nắp chữ U
│          │ B
└─── A ───┘

Đai nắp phối hợp cho dầm đổ sàn toàn khối. $L = A + 2B$.

✂ Quy tắc Ngắt Thép Gối & Thép Nhịp

  • Thép gối Lớp 1: Vươn vào từng nhịp một đoạn $L_1 = \max(L_{span}/4, L_{neo})$.
  • Thép gối Lớp 2: Vươn vào từng nhịp ngắn hơn: $L_2 = \max(L_{span}/5, L_{neo})$.
  • Thép nhịp giữa bụng: Cắt cách mép cột một khoảng $\Delta X = L_n/7$.
  • Bảo toàn kích thước: Bám sát 100% kích thước chỉ định từ ma trận Kata.xlsm (không áp thuật toán chia cây 11.7m giả định).

🔄 Quy chuẩn Phân bố 3 Vùng Đai & Cốt Sườn

  • Vùng gối trái: Bắt đầu từ $X = 50\text{mm}$ đến $L_n/4$, bước dày $s_{sup} = 150\text{mm}$.
  • Vùng giữa nhịp: Từ $L_n/4$ đến $3L_n/4$, bước thưa $s_{mid} = 200\text{mm}$.
  • Vùng gối phải: Từ $3L_n/4$ đến $L_n - 50\text{mm}$, bước dày $s_{sup} = 150\text{mm}$.
  • Thép sườn chống phình: Tự động bố trí khi chiều cao dầm $h \ge 700\text{mm}$ (hàng 20), khoảng cách giữa các hàng $\le 400\text{mm}$.

TRỤ CỘT 3 Cách Vẽ Thép trong Revit API (Revit API Rebar Modeling)

⚡ So sánh Chuyên sâu: CreateFromCurves vs CreateFromRebarShape

Thuộc tính Rebar.CreateFromCurves Rebar.CreateFromRebarShape
Cơ chế hình học Tọa độ vector 3D tự do (IList<Curve>) Gắn với RebarShape, co giãn qua Box (ScaleToBox)
Phụ thuộc Family Không phụ thuộc (Chạy trên mọi template sạch) Bắt buộc template phải có RebarShape tương ứng
Rebar Set (Mảng đai) Thường tạo từng thanh đai rời (Individual Bars) Tạo mảng rải siêu nhẹ qua SetLayoutAsNumberWithSpacing
Số element (150 đai) 150 elements (Nặng mô hình) Đúng 3 elements (3 vùng đai gối - nhịp - gối)
Thời gian tạo (150 đai) ~2,000 ms ~80 ms (Nhanh gấp 25 lần!)
Thống kê khối lượng Thống kê theo Total Bar Length Thống kê chi tiết A, B, C, D... theo Shape Code
⚠️ Short Curve Tolerance

Revit từ chối các đoạn thẳng $< 2\text{mm}$ ($1/16''$). Giải pháp: Chuẩn hóa bằng Polyline3.Simplify(1.0).

⚠️ Planar Geometry Enforce

Mọi Curve tạo Rebar phải đồng phẳng tuyệt đối. Phải chiếu vector chuẩn hóa trước khi gọi API.

✓ Single TransactionGroup

Gom toàn bộ thao tác xóa thép cũ và tạo thép mới vào 1 TransactionGroup duy nhất để hoàn tác an toàn.

TRỤ CỘT 4 Kiến trúc Hybrid Self-Resolving áp dụng cho HPRebar

🛡️ Cơ chế Tự Dò & Tự Động Fallback Thông Minh

Được thiết kế theo nguyên lý "Tối ưu khi có thể, an toàn trong mọi hoàn cảnh":

TẦNG 1: Ưu tiên RebarShape Driven (Rebar Set)

Khi vẽ thép đai kín chữ nhật (Mã 41): Kiểm tra trong project có family Shape đai (01, T1, M_T1 hoặc Shape 41). Nếu có $\rightarrow$ gọi Rebar.CreateFromRebarShape kết hợp ScaleToBox và SetLayoutAsNumberWithSpacing để sinh Rebar Set mảng rải siêu nhẹ.

TẦNG 2: Fallback an toàn tuyệt đối (Curves Engine)

Nếu template thiếu Family RebarShape, hoặc là các hình dạng phức tạp (Đai nắp U + Móc đan C), hoặc ScaleToBox ném ngoại lệ $\rightarrow$ hệ thống tự động fallback mượt mà sang Rebar.CreateFromCurves. Đảm bảo lệnh không bao giờ bị văng (100% crash-proof).

Mã nguồn mẫu C# chuẩn mực (Production Reference Code) HPRebar.KataRebar.Service.KataRebarCreationService 
// TẦNG 1: Shape-Driven Set
if (mainShape is not null && layout.StirrupZones.Count > 0)
{
    foreach (var zone in layout.StirrupZones)
    {
        if (zone.StirrupType == KataStirrupShapeType.ClosedHoop)
        {
            var localOrigin = new Point3(zone.StartStationX, -(spec.Width / 2.0) + spec.CoverStirrup, -spec.Height + spec.CoverStirrup);
            XYZ originXyz = mapper.ToXyz(localOrigin);
            XYZ xVec = mapper.AxisY; // Transverse width
            XYZ yVec = XYZ.BasisZ;   // Vertical height

            var rebar = Rebar.CreateFromRebarShape(doc, mainShape, barType, host, originXyz, xVec, yVec);
            var accessor = rebar.GetShapeDrivenAccessor();
            accessor.ScaleToBox(originXyz, xVec * RevitUnits.MmToFt(zone.OutToOutWidth), yVec * RevitUnits.MmToFt(zone.OutToOutHeight));
            accessor.SetLayoutAsNumberWithSpacing(zone.Count, RevitUnits.MmToFt(zone.Spacing), true, true, true);

            StampRebar(rebar, spec.BeamName);
            created.Add(rebar);
        }
    }
}

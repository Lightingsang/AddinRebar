## Decisions worth remembering

- **No transaction means "refuse before, not roll back after".** ETABS cannot undo anything, so the tier of a script is decided
  before it runs — from a 1 281-row allow-list generated by reflection over the installed wrapper and bound *semantically*
  (Roslyn's own symbols, so aliases, casts, lambdas and method groups resolve to the same `cInterface.Member`; anything unbound
  is destructive). A writing run saves the model and copies a `.EDB` snapshot first; a destructive one needs a second checkbox
  and is otherwise a JSON-RPC `-32001`, never a tool run — so a user's refusal can never quarantine a seed.
- **The registry's stability rule shapes error types.** A defined-but-not-run load case is the caller's to fix (run the analysis or
  pick another case), so the results seeds throw `ArgumentException`, not `InvalidOperationException` — otherwise five innocent
  "reactions before analysis?" questions would quarantine `get_joint_reactions`. Phase 4's shared-registry runs proved exactly that.
- **Path policy is two-pass by necessity.** The pipe thread knows nothing about the model folder; it refuses the shapes it cannot read
  (`args.Str(key, fallback)`, a shadowed `ScriptArgs`, concatenation) and the folders that are always wrong; the worker, which knows
  the model, refuses everything outside the model folder or `%LocalAppData%\HPEtabs` on the normalised path.
- **`#r`/`#load` were an engine hole for every host.** Directives are trivia the guard's syntax walker never visited, while the script
  compiler honoured them: a DLL from disk ran as tier R. Four lines in `ScriptGuard.Check`, two engine tests, all host suites green.

## What surprised us

- `File.Save(path)` is a save-as: it re-points the model and thereafter `GetModelFilename` returns the `.$et` working copy.
- `AddByCoord` creates the frame **and** its two points (`changed.added` = 3); deleting the frame orphan-deletes the points (−6).
- Unlocking the model discards every analysis result — the phase-1 open item, closed by a harness check.
- An ETABS started "some other way" has no running-object-table entry at all (`GetObject` and `GetObjectProcess` both null, the
  Tools menu item greyed); started from its shortcut and then File › Open, it registers at once. Root cause unproven.
- Reactions of a W14X500 column 3 m tall came back as 21.9 kN — the self-weight to three digits. The most convincing check of the day.
- Windows upper-cases `os.environ` keys; `dict(os.environ)["HPETABS_MCP_Registry__LibraryPath"]` is a KeyError while .NET binds it fine.

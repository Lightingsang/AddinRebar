## 4. Implementation Bug Escalation

### Bug Summary
- **Component**: `HPAutoCad.Loader`
- **File**: `HPAutoCad/HPAutoCad.Loader/HPAutoCadLoaderApplication.cs`
- **Line**: 61
- **Defect Class**: Reflection resolution failure (`System.Reflection.AmbiguousMatchException`)
- **Severity**: Critical (Blocks 100% of HPGeoLink commands in live AutoCAD)

### Verbatim Exception
```
System.Reflection.AmbiguousMatchException: Ambiguous match found for 'HPAutoCad.Entry System.Collections.Generic.IReadOnlyDictionary`2[System.String,System.Delegate] Start(System.String, System.Action`1[System.String])'.
   at System.RuntimeType.GetMethodImplCommon(String name, Int32 genericParameterCount, BindingFlags bindingAttr, Binder binder, CallingConventions callConv, Type[] types, ParameterModifier[] modifiers)
   at System.RuntimeType.GetMethodImpl(String name, BindingFlags bindingAttr, Binder binder, CallingConventions callConv, Type[] types, ParameterModifier[] modifiers)
   at System.Type.GetMethod(String name, BindingFlags bindingAttr)
   at HPAutoCad.Loader.HPAutoCadLoaderApplication.Initialize() in G:\09-PROJECT AI\01_Revit\02_CshapRevit\01_AddinRebar\HPAutoCad\HPAutoCad.Loader\HPAutoCadLoaderApplication.cs:line 61
```

### Root Cause Analysis
In `HPAutoCad/HPAutoCad/Entry.cs`, there are two public static `Start` methods:
1. `public static IReadOnlyDictionary<string, Delegate> Start(string appDirectory, Action<string>? log = null)`
2. `public static IReadOnlyDictionary<string, Delegate> Start(string appDirectory, string product, string acadVersion)`

In `HPAutoCadLoaderApplication.cs`:
```csharp
var start = entry.GetMethod(EntryMethodName, BindingFlags.Public | BindingFlags.Static)
            ?? throw new MissingMethodException(EntryTypeName, EntryMethodName);
```
`Type.GetMethod(name, bindingAttr)` throws `AmbiguousMatchException` when overloaded methods exist matching the flags. This prevents `Initialize()` from finishing, leaving `HPAutoCadLoaderApplication.App` null. Consequently, all commands (`HPGEOINFO`, `HPGEOKMZ`, `HPGEOIMAGE`, `HPGEOIMPORT`, `HPGEO`) report:
```
HPGEOINFO: HPAutoCad did not start (AmbiguousMatchException: Ambiguous match found for ...). See C:\Users\STR-HP03\AppData\Local\HPAutoCad\logs\loader.log
```

### Fix Recommendation for Implementing Agent
In `HPAutoCadLoaderApplication.cs`, update line 61 to disambiguate the overload:
```csharp
var start = entry.GetMethods(BindingFlags.Public | BindingFlags.Static)
                 .FirstOrDefault(m => m.Name == EntryMethodName && m.GetParameters().Length == 2)
            ?? entry.GetMethods(BindingFlags.Public | BindingFlags.Static)
                    .FirstOrDefault(m => m.Name == EntryMethodName)
            ?? throw new MissingMethodException(EntryTypeName, EntryMethodName);
```
After making the fix, build `HPAutoCad.Loader.csproj` (which deploys to `%AppData%\Autodesk\ApplicationPlugins\HPAutoCad.bundle\`).

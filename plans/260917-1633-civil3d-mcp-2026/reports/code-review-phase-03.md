# Code review — Phase 3: server profile, 12 seeds, tests, smoke harness

**Date:** 2026-09-18 · **Reviewer:** code-reviewer · **Scope:** uncommitted `HPCivil3d/` since `2388d3e` — 12 generated seeds (`Registry/SeedLibrary/**`, 536 lines of `code.cs`), `generate-seed-library.py`, `Prompts/`, `Resources/`, `ExecuteCivil3dCodeTool` description, `HPCivil3d.Mcp.Server.Tests` (5 files), mirror contract extension, `run-server-smoke.ps1`, README. Engine untouched (`git diff HEAD -- McpShared` empty).

**Score: 7 / 10** — the seeds use only verified members, convert units at the boundary the way ADR-03 says, refuse caller mistakes as `ArgumentException`, and every promise in the phase report checks out (build green, 84 + 55 tests, 13 observable skips, generator byte-idempotent, smoke 28/28 on disk). What holds the score down is the **64 KB envelope cap**: `list_pipe_networks` breaches it with its *default* arguments on a modest network, four list seeds allow a `limit` that turns the answer into a truncated text blob, and `get_alignment_geometry` has no cap at all on `entities` — the same class of defect every AEC phase review had to fix. One dead flag (`insunitsMismatch` in `get_civil_document_info`) and one test blind spot (nested `args` keys) round out the Mediums.

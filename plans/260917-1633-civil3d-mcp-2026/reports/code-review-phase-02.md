## Verified OK

- **Serializer vs the verified API surface.** `AlignmentSubEntity {SubEntityType, StartStation, EndStation, Length, StartPoint/EndPoint : Point2d}`, `AlignmentEntity {EntityType, EntityId : Int32, SubEntityCount : Int32}`, `AlignmentCurve : AlignmentEntity {StartStation, EndStation, Length}`, `CogoPoint : Autodesk.AutoCAD.DatabaseServices.Entity {PointNumber : UInt32, PointName, FullDescription, Easting, Northing, Elevation}`, `StyleBase : DBObject` with `Name` (live "Local Road") — every member used exists with that type (addendum §4, §9, §10). `CogoPoint` is **not** a Civil `Entity`, so `name` is written once (no duplicate key); case order `SubEntity` → `Entity` → AutoCAD `Entity` → `DBObject` is correct since the wrappers are not `DBObject`s. Aliases instead of `using Autodesk.Civil.DatabaseServices;` are the right call — that namespace has its own `Entity`/`DBObject`.
- **`IsAutocadType` prefix `Autodesk.`** now a token, not a block (byte-identical structure with AutoCAD); the converter factory therefore claims `Autodesk.Civil.*`/`Autodesk.Aec.*` (live C2/C3/C9 confirm), and `List<object>`/anonymous members dispatch to the runtime type.
- **Exception text** `{Type.Name}: {Message}` comes from the shared `catch (Exception)`; `Autodesk.Civil.*Exception` does not derive from `Autodesk.AutoCAD.Runtime.Exception`, so it never takes the `ErrorStatus` branch (live C8 `PointNotOnEntityException: Point Outside Surface.`).
- **`Civil3dUnitTable`** pure, linked into the test project; `Resolve` covers null → INSUNITS, agree, disagree (Feet over mm flagged), US survey feet = feet at 1e-4, unknown label → 1 mm/unit with a note, `"."`/blank zone → null. `Civil3dUnits` is readers only, every getter guarded with `Log.Debug`. Runner keeps the AutoCAD `var units = AutocadInsunits.For(...)` line and reassigns inside the block; context reader keeps `result.Units = …LabelFor(insunits)` then overrides — the "add-only block" convention holds in all four marked files (28 markers, all balanced, none in XAML yet — the XML regex is exercised only by the normalisation unit test).
- **Mirror normalisation** matches the `note`: ordered `Replace`, `CsBlock` (`^[ \t]*//…begin … ^[ \t]*//…end`, `Singleline|Multiline`, lazy → nested or unterminated blocks leave a stray marker line and fail loudly), CRLF → LF before regex, BOM trimmed, versions → `<version>`, blank lines / trailing whitespace dropped. Tokens: first entry `"HPAutoCad.McpBridge.BridgeEntry"` precedes `HPAutoCad.McpBridge` (ordering hazard resolved); no token's `autocad` string is a substring that rewrites unrelated code in a mirrored file (checked all 43 against both trees); dead-token and uniqueness tests present. Mutation re-run: one space in `Civil3dScriptRunner.cs` → exactly `Civil_file_equals…` for that row fails, naming the line.
- **Test project isolation.** References `McpShared/HPRebar.McpBridge.Core` only + one linked Civil file; no `AutoCAD.NET`, no `Aecc*`, no `HPAutoCad` project reference (HPAutoCad is read as text — the intended mechanism). `HPCivil3d/` → `McpShared/` only, slnx comment states it.
- **Harness safety.** `Assert-NoAutocadRunning` first; `Stop-Acad` = inner PowerShell that throws unless `Get-Process acad` is exactly one pid equal to `$p.Id`, closes each document `Close($false)` then `Quit()`, 45 s grace, `Stop-Process -Id $p.Id` fallback — never a foreign pid, and the same guard is used for `-Product ACAD`/`ADVS` (both register `AutoCAD.Application`; the harness started them with an empty drawing). `Answer-SecureLoad` clicks **Load Once** only when `GetWindowThreadProcessId(dlg) == $script:acadPid` (unset → left alone). `Set-OptIn`/`Find-OptInCheckbox` via UIA `ProcessIdProperty`; `press_escape` enumerates windows by pid; `cancel_command` fallback `AppActivate(pid)` before `SendKeys`. `.dwl/.dwl2 -Force` sweep scoped to `output/live-verify/scene` before and in `finally`; drawings are copies. Exit codes: pipe = number of failed steps (+ Python exit 1 on any check), ribbon 0/1/2 (2 = MANUAL only), spike `$fails`. Env cleanup complete in pipe + spike scripts.
- **Descriptions consistent** (Feet default, `insunitsMismatch`, mm at the boundary, `civil` never null in Civil 3D): `ExecuteCivil3dCodeTool`, `Civil3dHostProfile.ScriptContractSummary`, `Civil3dContextTool`, README §Script contract, `Civil3dUnitTable` summary, `Civil3dScriptGlobals` class summary — except the field summary in #3 and the tooltip in #7.
- **Repo rules.** File-scoped namespaces everywhere (`Program.cs` is top-level statements); every class `sealed`/`static`/`partial Window`; `Nullable enable` ×4; longest `.cs` 285 (`Civil3dScriptRunner`), 273 (serializer) — none ≥ 300; no `phase`/`M#`/`L#`/`U#`/`S-#` in code comments apart from #8 (harness labels excluded by design). `output/` gitignored (the S-03 `acad-tools-library` copy under it is not tracked).

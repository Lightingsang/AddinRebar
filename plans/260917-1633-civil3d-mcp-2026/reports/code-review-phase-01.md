# Code review — Phase 1: `HPCivil3d/` scaffold, bundle, spike harness

**Date:** 2026-09-18 · **Reviewer:** code-reviewer · **Scope:** uncommitted `HPCivil3d/` (3 projects, 2 harness scripts + 1 Python, props/slnx/README, `tools/mirror-tokens.json`) + phase-1 plan/ADR updates · **Engine:** `git diff --stat HEAD -- McpShared` empty (verified) · **HPAutoCad:** unchanged.

**Score: 7.5 / 10** — faithful copy of the AutoCAD bridge with every drift Civil-motivated, build green, missing-Civil gate verified, harness pid-guarded and copy-only. No High. Four Mediums are hardening / phase-2 readiness, none blocks commit.

## Method

- Applied `tools/mirror-tokens.json` (ordered) to every file of `HPAutoCad/HPAutoCad.McpBridge{,.Loader}` and diffed against the Civil copy (script in session scratchpad). 20 of 29 file pairs **byte-identical after tokens** (all Loader `.cs` but 2 comments, both XAML themes, status view + code-behind, `AutocadVersionMap`, `DatabaseChangeCounter`, `ThemeSwitcher`, loader csproj, launchSettings). 9 drifted — every hunk is one of: `civil` global, Civil API references, units, Civil context block, serializer prefix, `Aec` load-context prefix, `Platform="Civil3D"` manifest, `#if DEBUG` spike bypass, AEC-engine removal. **No unexplained drift.**
- `dotnet build HPCivil3d.slnx -c Debug -p:DeployBundle=false` → **0 errors, 2 warnings** (MSB3277 `Aecc*Mgd`/`System.Drawing 4.0 vs 8.0`, already in plan). `-p:Civil3dInstallDir=X:\nowhere\` → bridge **1 readable error** (`RequireCivil3dApi`, names both probed paths + both overrides), server **0 errors**. `-getProperty` resolves `C:\Program Files\Autodesk\AutoCAD 2026\C3D\` / `…\ACA\` / `true` from the registry key.
- Bridge `bin/Debug/net8.0-windows/` (21 files) and the deployed `Contents\Bridge\`: **no `Ac*`/`Aec*`/`Autodesk*`/`AdWindows` DLL** — `Private=false` holds, nothing from Program Files ships.
- Grep sweeps: token misses, GUIDs, ribbon ids, pipe names, env-var readers, plan codes in comments, namespaces/sealed/nullable/line counts, server API isolation, dependency direction.

## Verified OK

- **Token rename complete.** Only intentional `HPAutoCad`/`HPMCPBRIDGE`/`hpautocad-mcp` references remain (S-03 coexistence step, README/slnx/manifest prose). `ProductCode` `{04F557F5-…}` ≠ AutoCAD `{7B4E9C2D-…}`; ALC name `HPCivil3d.McpBridge`; entry `HPCivil3d.McpBridge.Civil3dBridgeEntry`; commands `HPC3DMCPBRIDGE/START/STOP/STATUS` (no spike commands added — good, smaller surface); ribbon ids `HPCIVIL3D_MCP_TAB/PANEL/BRIDGE`, title `HPCivil3d`; pipe `hpcivil3d-mcp-2026`; log/settings/audit under `HPCivil3d\McpBridge`; `AutodeskProduct="AutoCAD"` kept deliberately (ADR-02 §"giữ").
- **Spike bypass scope.** `GuardProfile.Civil3d` = `Autocad` lists + Civil extras (`GuardProfile.cs:111-127`), so the fallback keeps every AutoCAD denial (prompts, `StartTransaction`, `SendStringToExecute`, reflection, IO…). `HPCIVIL3D_MCP_SPIKE` has **exactly one reader** (`MainThreadExecutor.cs:97`); the harness sets it (`run-spike.ps1:56`), unsets before isolation (`:93`) and in `finally` (`:149`). `Analyze` (`:159`) stays on `Civil3d`. Env var lives in `acad.exe`'s process environment — an MCP client over the pipe cannot set it. Adequate as an **interim** only because Debug is the deployed configuration (finding 1); phase-2 removal is load-bearing.
- **`Civil3dDocumentAccess`**: both getters wrapped, `Log.Debug` + null/"Unknown". Called only on the main thread (runner via `MainThreadQueue`, context via `GetContextAsync`), never on the pipe thread.
- **`Civil3dUnits`**: Meters → 1000, Feet → 304.8 (`ForDrawingUnit`), unknown → 1 + note; INSUNITS fallback when `civil` null; mismatch note replaces the unit note (only reachable for non-Meters/Feet, which the enum cannot produce). `"."`/empty → `coordinateSystemCode` null (spike U11). Live: `align-units.json` Meters/1000/`InternationalFoot`; context omits the null code.
- **`Civil3dContextReader`**: `Civil3dInfo` positional order matches `ContextMessages.cs:128-139`; null-civil branch fills `IsCivilDocument=false`, counts 0; counts read id collections only, each wrapped. `RevitVersion = hostVersion` kept as in AutoCAD (known compat gap).
- **`Civil3dResultSerializer`**: prefix `Autodesk.` covers `Autodesk.Civil.*`/`Autodesk.Aec.*`; converter's `default` branch is `ToString()` only (no property reflection → no path leak beyond what AutoCAD already had); `Autodesk.Civil.DatabaseServices.Entity : Aec.Entity : AutoCAD.Entity`, so the `case Entity` + `name` addition binds.
- **`Civil3dScriptRunner`**: only the units/`civil` hunk differs from the reviewed AutoCAD runner (two-transaction shape, wrapper disposal, `RollBack`, `AbortNested`, timeout-after-return, `none`+modify refusal all intact); `civil` read before `LockDocument` is a static lookup, spike W1/W2 ×2 pass.
- **`Directory.Build.props`**: resolution order matches the plan; `HasTrailingSlash` normalisation; `AecBaseDir = GetFullPath(C3D\..\ACA\)`; gate verified both ways (above). Applies to the server project too but only defines properties — server has no gate/refs and built with the bogus dir.
- **Loader/Bundle**: `Private=false` ×3, no `ProjectReference` to `HPAutoCad.Aec`, `DeployBundle` touches only `HPCivil3d.McpBridge.bundle\Contents\Bridge` (RemoveDir) — never another bundle. `BridgeLoadContext.HostAssemblyPrefixes` += `"Aec"` so `Aec*/Aecc*` are never duplicated. Loader catches `TargetInvocationException` and unwraps (plan risk: load in plain AutoCAD → logged, not thrown).
- **Harness safety**: `Assert-NoAutocadRunning` at start; `Stop-Acad` by the pid it started; `acad_com` refuses unless **exactly one** `acad.exe` exists **and** its pid == `HP_HARNESS_ACAD_PID`; `press_escape` enumerates windows by pid; drawings are **copies** in `output/live-verify/scene/` (Program Files never written); `.dwl` sweep before run; opt-in cannot persist (`BridgeSettingsStore.Save/Load` force `ExecutionEnabled=false`, engine) and the process is killed anyway; both `finally` blocks kill only `$civil`/`$acad`; `spike.py` kills its detached PowerShell children. `spike.scr` generated into `output/` at run time (not committed — better than the plan's static file).
- **Repo rules**: all `.cs` file-scoped namespaces; every class `sealed` or `static` except the WPF `partial class … : Window` (same as AutoCAD); `Nullable enable` ×3; longest `.cs` 284 lines (`Civil3dScriptRunner`), none ≥ 300; `spike.py` 640 (Python, exempt). Server references only `McpShared/HPRebar.Mcp.Server.Core`; the only `Autodesk` strings are namespace names inside the tool description. `HPCivil3d/` → `McpShared/` only; `HPAutoCad/` never referenced (S-03 uses the AutoCAD **exe path** from the harness, not a project reference). `.gitignore` covers `bin/ obj/ output/ *.user`; `git add -n` shows no artefacts; `global.json` identical to HPAutoCad.
- **Plan/ADR bookkeeping**: ADR-01 A (user-confirmed), ADR-02 Accepted, ADR-03/04/05 Accepted (revised) with spike evidence; phase file todo has only the review pair open. README token table + phase-2 mirror-test promise consistent with `mirror-tokens.json` apart from finding 2.

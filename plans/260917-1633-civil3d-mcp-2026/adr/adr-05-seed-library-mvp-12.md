## Context
User chốt 12 seed; ADR này kiểm từng seed **có member API thật** để viết, chốt schema/envelope, và ghi gì `[chưa xác minh]`. Cùng đường `civil3d.execute` như ad-hoc code (Revit ADR-05: **không** native command cho tool).

### Vì sao cặp ghi này (không phải cặp khác)
- **`create_cogo_points`:** ghi đơn giản nhất, không cần style đặt tên (dùng command settings của DWG), có `Abort()` thật, `Changed.Added = n` đo được bằng HANDSEED — bài kiểm dryRun sạch cho spike W1.
- **`create_alignment_from_polyline`:** thao tác Civil "thật" đầu tiên (polyline → alignment là bước phổ biến nhất khi bắt đầu), lộ ba điểm cần spike: style phải tồn tại, siteless `""`, dependency (alignment mới không có profile → không kích rebuild). Thay thế đã cân: `create_tin_surface_from_points` (`TinSurface.Create(db, name)` + `AddVertices` — cần surface style; giá trị tương đương nhưng trùng chủ đề với R5/R6) → giữ làm **follow-up seed**; `add_surface_vertices`/`assign_pipe_slope` phụ thuộc rebuild/rules → không MVP.

### Seed file chuẩn (copy khuôn AutoCAD)
`tool.json` (`name, category, transaction, description, inputSchema, tags:["seed","civil3d"], host:"civil3d"`), `code.cs` (script body, `return`), `examples.json` (≥ 2 ví dụ args). Sinh bằng tay (12 seed, không generator như ETABS — YAGNI). `_seeds.json` checksum như AutoCAD.

### Tests (phase 3)
- `SeedLibraryStructureTests` (net10): 12 seed đúng category của profile, `args.X("literal")` ⇔ `inputSchema` (analyzer), `transaction` đúng bảng, tag `civil3d`, `limit` có `maximum ≤ 500`, description nêu đơn vị, mọi field số trong `examples`/schema có hậu tố `Mm` hoặc thuộc danh sách drawing-unit (ADR-03 §Consequences).
- `SeedLibraryCompileTests` (net10, **cần Civil 3D cài**): compile mỗi `code.cs` với `Civil3dImports` + globals class `Civil3dScriptGlobals` shape (usings + fields) + reference `AutoCAD.NET 25.1.0` (NuGet cache) + `AeccDbMgd.dll`/`AecBaseMgd.dll`/`AeccPressurePipesMgd.dll` từ install dir (env `HPCIVIL3D_C3D_DIR` → registry `ACAD-9100:409\Location` + `C3D\` → `%ProgramW6432%`) — `Assert.SkipWhen(dir is null, "Civil 3D 2026 not installed")` quan sát được như ETABS; guard `GuardProfile.Civil3d` pass; không `Rebuild`/`DataShortcuts`.
- Live (phase 4): mỗi seed trên scene copy từ E6 (`Align-1.dwg`, `Surface-*.dwg`, `Corridor-*.dwg`, `Pipe Networks-*.dwg`, `Parcel-*.dwg`, `Points-*.dwg`) + W1/W2 dryRun rồi thật rồi `U`.

## Alternatives rejected
- 21 seed như Revit / port `mcp-servers-for-civil3d` nào đó: không có thư viện nguồn; 12 đủ cho loop registry và bao 6 họ object.
- Seed `rebuild_corridor`/`run_corridor_rebuild_all`: ADR-04 chặn MVP.
- Seed nhận đường dẫn (`import_landxml`, `export_points_csv`): cần path policy → follow-up.
- Category `Site` riêng: parcel/feature line đều qua site — gộp vào `Parcel` (R9 nhận `site`); alignment theo site vào `Alignment`.

## Consequences
- 24 tool trên server (4 core + 8 registry + 12 seed) — bằng Navis/ETABS MVP.
- Description mỗi seed nêu đơn vị từng field; `drawingUnit` xuất hiện trong mọi envelope.
- `list_parcels` MVP thiếu diện tích — ghi known gap tới S-09.

## Positive observations
- `MainThreadQueue` is genuinely host-neutral and its ordering rules are unit-tested with a fake clock; the executor stays a thin adapter.
- The runner encodes the live findings in code comments that explain *why* (serialize before commit, counts before inner commit, document vs database manager) — the next reader does not need the report.
- Exception containment is complete: `OnTick` catches everything from `Work`, the runner catches AutoCAD/OCE/generic separately with `ErrorStatus` surfaced, and the dispatcher maps `BridgeRequestException` to its own code.
- `DatabaseChangeCounter` holds only `ObjectId` structs — the crash class from run 7 cannot recur through this path.
- Light theme as an override dictionary layered over dark keeps every token a `DynamicResource`; `AutomationId`s make the window scriptable.
- Spike code and commands removed as the plan required, README and ADRs updated in the same commit.

## Spike gates referenced above (details in [phase-00](../phase-00-spikes.md))

- **S0-A ILRepack**: `dotnet build HPRebar/HPRebar.slnx -c Debug.R26 -p:DeployAddin=false` (then `Debug.R24`) with the toolkit merged; `HPRebar.dll` must (1) contain `themes/materialdesign2.defaults.baml` + `resources/roboto/*.ttf` + a merged `themes/generic.baml`, (2) show every BAML pack URI rewritten to `HPRebar;component`, (3) open `ColumnRebarView` in Revit 2026 with a MaterialDesign-styled `Button` and `ComboBox` popup, no `XamlParseException`, dark→light swap by `SetTheme`.
- **S0-B two ALCs**: HPAutoCad bridge + HPGeo both carrying the toolkit in one acad.exe; open both windows in both orders; gate = both windows render their own theme, `ComboBox` popup opens in HPGeo, no `XamlParseException`, `loader.log` shows each ALC loading its own `MaterialDesignThemes.Wpf`. Fallback if it fails: repack the toolkit into each bridge assembly (`ILRepack` in the bridge csproj, internalized) so the simple name never appears twice.
- **S0-C net48 resolver**: HPNavis with the three names allow-listed; plant `MaterialDesignThemes.Wpf 4.9.0` in a throw-away sibling plugin folder; gate = our window opens with 5.3.2 (`Resolved` log line), the planted copy never answers our request, Roamer with the foreign `NavisworksMCPPlugin` beside still starts silently.

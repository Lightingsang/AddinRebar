The pure core is the right shape: `StructuralMember` is a record with `Shape`/`Axis` `[JsonIgnore]`d and a `Describe` projection, the three checks are pure and `ct`-aware, ids are assigned after `AuditIssue.Ordered` (stable on reversed input, probed), `WriteTags` is two-phase (`SpaceId` in phase 1, `GetObject(ForWrite)` + `EnsureLayer` only after the atomic gate, `SetDatabaseDefaults` before `LayerId`), every seed is a thin shim with the caps of the check tools pinned to `MaxIssueLimit`, and the harness drives every tool live including apply/preview/idempotence. Pinned (10): grid labels/directions/intersections/spacing on a friendly detached-bubble grid; reach extension + far bubble ignored; sections/axes/default prefixes; connectivity landed / 20 mm gap / free end / exact duplicate ignored; free beam = 3 criticals; alignment loose/tight/no-grid-for-one-column; opening through/near/outside; reading order + kept + reserved + renumber + bad `sortBy`; schedule rows. `SeedLibraryTests` pins shim shape, `transaction`, caps of the five read tools (not grids).

## Positive

`StructuralMember.From` derives footprint/run/axis from `ShapeMetrics` with the dominant-direction rule, so a square column has no axis to mis-align on; `Section` is a computed property, `Shape`/`Axis` `[JsonIgnore]`d and never serialised (the item projection is explicit in `Describe`); `MemberKind.Rank`/`DefaultPrefix`/`Supports` centralise the vocabulary and the schedule order; `GridDetector` extends lines by the reach so bubbled lines cross (pinned), sorts by direction → position → handle and names intersections `A/1` with both handles; `StructuralChecks` are pure, `ct`-aware, use the spatial index for supports, exclude the exact self-duplicate, carry a real `locationMm` and a measured `valueMm`, and number after `AuditIssue.Ordered` (critical first, ids stable on reversed input); `MemberTagging.Assign` skips taken numbers per kind and keeps existing marks with a matching prefix; `WriteTags` is two-phase in the right order (`SpaceId` → validation → atomic gate → `GetObject(ForWrite)` → `EnsureLayer` → append), `SetDatabaseDefaults` before `LayerId`, `AdjustAlignment` after append, `apply: false` returns before anything is opened for write, a locked/frozen tag layer is a structured `LAYER_LOCKED`/`LAYER_FROZEN`; attribute writes reuse `BlockService.ValidateAttributes`/`WriteAttributes` (attribute layer checked); `start`/`digits`/`sortBy`/`space`/layer-name refusals are `ArgumentException`s; `StructuralInputs` reports unknown filter/tolerance keys; seeds are thin shims, every declared arg is read with a literal, `Structural` category added and pinned; harness N/M cover every tool live including preview, apply, idempotence, dryRun and the table.

## Implementation Steps

1. **Cài Nice3point.Revit.Templates (nếu chưa có):**
   ```bash
   dotnet new install Nice3point.Revit.Templates
   ```

2. **Scaffold project:**
   ```bash
   cd /Users/tonyhoang/Documents/GitHub/revit-api-2027-with-claude
   dotnet new revit-addin \
     -n RevitDuplicateSheet \
     -o RevitDuplicateSheet \
     --addinManifestType application \
     --addinUiWpf true \
     --addinDiMode container \
     --addinLogging true
   ```

3. **Verify scaffold output:**
   - Confirm folder structure khớp `docs/system-architecture.md §2`.
   - Confirm `.csproj` có `Sdk="Nice3point.Revit.Sdk"`.
   - Confirm có `Application.cs` kế thừa `Nice3point.Revit.Toolkit.External.ExternalApplication`.

4. **Add placeholder icons:**
   - Tạo `Resources/Icons/RibbonIcon16.png` (16×16) + `RibbonIcon32.png` (32×32). Có thể copy từ Nice3point template hoặc generate PNG đơn sắc.

5. **Smoke build R27 only (multi-version sẽ thêm Phase 2):**
   ```bash
   cd RevitDuplicateSheet
   dotnet build -c Debug.R27
   ```
   - HARD-GATE: phải pass. Fail = block, không sang Phase 2.

6. **Commit baseline:**
   - `feat: scaffold RevitDuplicateSheet add-in via Nice3point template`

## Risk Assessment

| Risk | Mitigation |
|---|---|
| Nice3point template chưa cài | Step 1 cài sẵn; nếu fail offline → fallback clone https://github.com/Nice3point/RevitTemplates và `dotnet new install <local-path>` |
| Tên project conflict folder root | Folder `RevitDuplicateSheet/` chưa tồn tại — verify trước khi run scaffold |
| Build R27 fail vì SDK version cũ | Yêu cầu .NET 8 SDK installed (`dotnet --list-sdks` phải có 8.x) |
| Placeholder icon không hiển thị ribbon | Phase 3 sẽ replace bằng icon thật; placeholder OK miễn file tồn tại |

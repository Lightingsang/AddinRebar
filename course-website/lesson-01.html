PHẦN 02 / 08

Triết Lý Vibe-Coding

Trước khi gõ dòng prompt đầu tiên, bạn phải hiểu tại sao chúng ta làm việc theo cách này. Nếu không, bạn sẽ vẫn ngồi gõ tay từng dòng code như 10 năm trước.

Khái Niệm Cốt Lõi

Vibe-Coding là gì?

Là phương pháp lập trình mà bạn ra mô tả bằng tiếng Việt/Anh, AI viết toàn bộ code, bạn chỉ review plan trước khi AI code và kiểm tra kết quả sau khi AI chạy xong. Bạn không gõ tay, không debug, không đọc lỗi compiler.

📊 So Sánh 2 Cách Tiếp Cận

❌ Code Tay (cách cũ)

  • Học cú pháp C# 3-6 tháng
  • Đọc Revit API docs hàng nghìn trang
  • 1 add-in mất 2-4 tuần
  • Debug từng warning, từng lỗi
  • Phải nhớ tên hàm, tên class
  • Code lặp lại 90%, mệt

✅ Vibe-Coding (cách mới)

  • Học prompt + concept (1 tuần)
  • AI đọc docs giúp bạn
  • 1 add-in mất 5-30 phút
  • AI tự đọc lỗi, tự sửa
  • Nói tiếng Việt, AI hiểu
  • Tập trung nghiệp vụ, không syntax
Nguyên Tắc Vàng

Quy tắc 99/1 — 99% AI, 1% bạn

Trong khóa học này, bạn sẽ không chạm tay vào file .cs nào quá 1%. Toàn bộ: tạo file, sửa file, đặt tên, refactor, thêm thư viện, build, test, fix lỗi — đều là việc của AI.

Việc của bạn là 3 thứ duy nhất:

  1. Mô tả mục tiêu — viết prompt rõ ràng bằng tiếng Việt
  2. Review plan — đọc kế hoạch AI đề xuất, chấp nhận hoặc điều chỉnh
  3. Kiểm tra kết quả — bấm F5, xem add-in chạy đúng không trong Revit
PHẦN 03 / 08

Cài Nice3point RevitTemplates

Nice3point RevitTemplates là bộ scaffolder chính thức của cộng đồng Revit (422★ trên GitHub). Nó giúp bạn tạo 1 project Revit Add-in hoàn chỉnh trong 30 giây — đã có sẵn MVVM, DI, Serilog, multi-version, auto-deploy.

Khái Niệm Quan Trọng

Template Engine là gì?

.NET Template Engine là cơ chế của .NET cho phép bạn cài các "khuôn mẫu" project. Khi bạn gõ dotnet new revit-addin, .NET sẽ sinh ra toàn bộ cấu trúc thư mục, file .csproj, file .addin, code mẫu — sẵn sàng build ngay.

Thay vì copy-paste project cũ rồi đổi tên (dễ sót), bạn dùng template = chuẩn hóa = không lỗi.

⚙️ Cài Đặt Một Lần Duy Nhất

Mở terminal (PowerShell / Terminal / iTerm)

Trên Windows: nhấn Win + R → gõ powershell. Trên Mac: Cmd + Space → gõ terminal.

Chạy lệnh cài template

$ dotnet new install Nice3point.Revit.Templates

Lệnh này tải template từ NuGet và đăng ký vào hệ thống. Mất ~20 giây. Bạn chỉ cần làm 1 lần duy nhất cho cả đời.

Kiểm tra cài đặt thành công

$ dotnet new list revit

Nếu thấy danh sách 6 templates (revit-addin, revit-application, v.v.), bạn đã cài thành công.

📦 6 Templates Có Sẵn

Mỗi template tương ứng một loại project. Trong khóa học, ta dùng chính revit-addin (đơn giản) và revit-solution (production-grade).

revit-addin

🧩 Single Project

Quickstart 1 project, gọn nhẹ. Dùng cho Hello World và bài tập buổi 1.

revit-application

⚓ Modular Entry

Có entry-point tách biệt, dễ scale. Dùng khi muốn modular hóa.

revit-module

🧱 Business Module

Module nghiệp vụ riêng, plug vào application. Tách concerns rõ.

revit-solution

🏭 Enterprise

Full solution: app + tests + CI/CD + installer. Dùng cho buổi 3-4.

revit-benchmark

⏱️ Performance

Đo performance code chạy trong Revit thread. Optimize bottleneck.

revit-test

🧪 Unit Tests

TUnit framework, có access full Revit API. Test isolation trong Revit.

💡

Đừng nhớ 6 cái này. Cứ hỏi Claude Code: "Tôi muốn làm add-in X, dùng template nào?" — AI sẽ chọn đúng. Đây là tinh thần vibe-coding.

Tạo Project Revit Đầu Tiên

Giờ ta tạo project thực tế. Khác với khóa học khác bắt bạn gõ lệnh, ở đây ta để Claude Code làm tất cả — bạn chỉ ngồi xem và confirm.

Tạo thư mục project

$ mkdir ~/RevitAddins $ cd ~/RevitAddins

Đây sẽ là thư mục chứa tất cả add-in của bạn trong khóa học.

Khởi động Claude Code

$ claude

Claude Code sẽ mở interactive session. Bạn gõ prompt bằng tiếng Việt được — AI hiểu hết.

Ra lệnh cho AI tạo project

Đây là prompt đầu tiên trong cuộc đời lập trình Revit của bạn. Copy nguyên đoạn dưới đây:

Prompt #1 — Tạo Project
Hãy tạo cho tôi một project Revit Add-in mới bằng Nice3point template. - Tên project: HelloRevit - Template: revit-addin (single project quickstart) - Multi-version: hỗ trợ Revit 2023, 2024, 2025, 2026, 2027 - Manifest type: application - Dependency Injection: bật (hosting mode) - Logging: bật Serilog Sau khi tạo xong, hãy: 1. Mở file .csproj cho tôi xem 2. Giải thích cấu trúc thư mục vừa sinh 3. Cho tôi biết file nào là entry point

AI tạo plan — Bạn review

Claude Code sẽ không chạy lệnh ngay. Nó sẽ trình bày kế hoạch trước:

  • Lệnh sắp chạy: dotnet new revit-addin -n HelloRevit ...
  • Cấu trúc thư mục dự kiến
  • Các file sẽ được sinh

Bạn đọc plan, nếu OK thì gõ yes hoặc nhấn Enter để confirm. Đây chính là "review plan" — bước quan trọng nhất.

Xem cấu trúc project được sinh

Sau khi AI chạy xong, thư mục HelloRevit/ sẽ có:

HelloRevit/ ├── Application.cs ← Entry point (IExternalApplication) ├── Host.cs ← Dependency Injection bootstrap ├── HelloRevit.csproj ← Project file (SDK=Nice3point.Revit.Sdk) ├── HelloRevit.addin ← Revit XML manifest ├── Commands/ │ └── StartupCommand.cs ← Logic button trên Ribbon ├── Configuration/ │ ├── HostingConfiguration.cs │ └── LoggerConfiguration.cs ├── Models/ ← Data layer (rỗng) ├── ViewModels/ │ └── MainViewModel.cs ← MVVM (CommunityToolkit.Mvvm) ├── Views/ │ ├── MainView.xaml ← WPF UI │ └── MainView.xaml.cs └── Resources/Icons/ ├── RibbonIcon16.png └── RibbonIcon32.png
Khái Niệm

Multi-version Build là gì?

Revit 2023, 2024, 2025, 2026, 2027 dùng RevitAPI.dll khác nhau và .NET version khác nhau:

  • Revit 2023-2024: .NET Framework 4.8
  • Revit 2025-2027: .NET 8.0

Bình thường bạn phải tạo 5 project khác nhau. Nhưng Nice3point có MSBuild SDK tự pick đúng phiên bản: khi bạn chọn config Debug R27, nó link đúng RevitAPI 2027.dll và compile với .NET 8. Code C# dùng #if REVIT2027_OR_GREATER để xử lý API khác nhau giữa các version.

PHẦN 05 / 08

Add-in "Hello World" — Button Đầu Tiên

Bây giờ ta sẽ làm add-in đơn giản nhất: 1 button trên ribbon Revit, click vào hiện popup "Hello World". Mục tiêu: chứng minh add-in chạy được, debug được.

Khái Niệm

IExternalCommand vs IExternalApplication

  • IExternalApplication — chạy 1 lần khi Revit khởi động. Dùng để tạo Ribbon panel, buttons.
  • IExternalCommand — chạy mỗi khi user click button. Đây là nơi viết logic nghiệp vụ.

Template đã sinh sẵn Application.cs (Application) và StartupCommand.cs (Command). Bạn không cần viết từ đầu.

🚀 Tạo Button "Hello World"

Ra lệnh cho AI

Prompt #2 — Hello World Button
Trong project HelloRevit: 1. Sửa Application.cs để tạo một Ribbon Panel tên "Khóa Học AI" trong tab "Add-Ins" 2. Trong panel đó, thêm 1 button có: - Text: "Hello World" - Icon: dùng sẵn Resources/Icons/RibbonIcon32.png - Tooltip: "Click để chào thế giới" 3. Sửa StartupCommand.cs để khi click button hiện MessageBox với nội dung: "Xin chào! Đây là add-in Revit đầu tiên của tôi được tạo bằng AI." 4. Cấu hình project để khi tôi nhấn F5: - Build .csproj với config Debug R27 - Auto-copy DLL + .addin vào %ProgramData%\Autodesk\Revit\Addins\2027\ - Tự động mở Revit.exe 2027 - Attach debugger để tôi đặt breakpoint được Sau khi xong, giải thích cho tôi từng file đã thay đổi.

AI viết code, bạn review

Claude Code sẽ thay đổi 2-3 files. Mỗi thay đổi nó sẽ cho bạn xem diff (trước/sau). Bạn chỉ cần nhìn và confirm.

💡

Không hiểu code? Không sao. Gõ tiếp: "Giải thích cho tôi từng dòng" hoặc "Đoạn này làm gì?". AI sẽ giảng cho bạn như giáo viên 1-1.

Nhấn F5 — Revit tự mở

Đây là khoảnh khắc thần kỳ:

  1. VSCode build project (~10-30 giây cho lần đầu)
  2. DLL được copy vào folder Revit Addins tự động
  3. Revit 2027 tự khởi động
  4. Bạn vào tab Add-Ins → thấy panel Khóa Học AI → button Hello World
  5. Click vào → popup hiện ra: "Xin chào!..."

Đặt breakpoint và debug

Trong VSCode, mở StartupCommand.cs, click vào lề trái của dòng TaskDialog.Show(...) để đặt breakpoint (chấm đỏ). Quay lại Revit, click button — debugger sẽ dừng ngay tại dòng đó. Bạn xem được giá trị biến, step qua từng dòng, modify rồi tiếp tục.

🎉

Chúc mừng! Bạn vừa tạo add-in Revit đầu tiên — bằng tiếng Việt, không gõ một dòng C# nào. Đây là chuẩn mực mới của khóa học. Từ giờ, mọi add-in đều theo flow này.

PHẦN 06 / 08

Bài Lab Thực Hành Trong Buổi

Sau Hello World, ta làm 5 lab khó dần. Mỗi lab là một prompt cho AI — bạn copy, paste, F5, xem kết quả. Mỗi lab dưới 10 phút. Không gõ code tay.

🎯 Lab 1 — Selection Elements

Tạo button "Đếm Elements" — user chọn nhiều object trong Revit, click button, popup hiện số lượng và loại từng object.

Thêm button mới "Đếm Elements" vào panel "Khóa Học AI". Khi click: lấy current selection từ UIDocument, hiện TaskDialog với tổng số element và breakdown theo Category.

📄 Lab 2 — Duplicate Sheet

Tạo button "Nhân Bản Sheet" — user chọn 1 sheet trong Project Browser, click button, sheet được clone với tên mới + suffix "(Copy)".

Tạo command DuplicateSheetCommand. Lấy sheet đang active, dùng ViewSheet.Create() để clone, copy tất cả viewports, đặt tên mới. Wrap trong Transaction.

🖼️ Lab 3 — Duplicate View

Tương tự Lab 2 nhưng cho View (floor plan, section, 3D view). Test với cả ViewDuplicateOption (Duplicate vs WithDetailing).

Tạo button "Nhân Bản View". Detect loại view đang active, dùng View.Duplicate(ViewDuplicateOption.WithDetailing), đặt tên mới có timestamp.

📊 Lab 4 — Import Sheets từ Excel

Tạo button "Import Sheets" — user chọn file Excel có cột [Sheet Number, Sheet Name], add-in tạo hàng loạt sheet trong Revit.

Cài NuGet ClosedXML. Tạo command đọc Excel, parse rows, tạo ViewSheet.Create() cho từng row trong 1 transaction. Report kết quả: X sheets created, Y errors.

🏗️ Lab 5 — Tạo Cốt Thép Rầm/Sàn từ Family

Add-in nâng cao: load family rebar, đặt instance vào cấu kiện dầm hoặc sàn đã chọn, theo grid cài đặt sẵn.

Tạo button "Tạo Cốt Thép". User chọn dầm/sàn. AI load family Rebar mẫu, tính bố trí theo cover & spacing, dùng Rebar.CreateFromCurves() để place. Visualize trong 3D view.
⚡

Khi AI gặp lỗi build: Đừng panic. Cứ gõ "build bị lỗi, hãy đọc và sửa". AI sẽ chạy dotnet build, parse lỗi, sửa code, build lại — vòng lặp tự động cho đến khi pass. Bạn ngồi uống cà phê.

PHẦN 07 / 08

Tại Sao Phải Dùng Skill?

Đến đây bạn đã làm được vài add-in. Nhưng nếu chỉ ra prompt linh tinh, code sẽ không nhất quán: chỗ thì có error handling, chỗ không; chỗ wrap transaction, chỗ không; chỗ có log, chỗ không. Skill giải quyết vấn đề này.

Khái Niệm Cốt Lõi

Skill là gì trong Claude Code?

Skill là quy trình chuẩn hóa mà bạn dạy cho AI làm theo mỗi khi develop. Ví dụ skill revit-feature-dev sẽ bắt AI:

  1. Plan trước — viết kế hoạch chi tiết các file sẽ tạo/sửa, transaction names, error cases
  2. User review plan — bạn duyệt plan, có thể sửa
  3. Implement — AI mới bắt đầu code theo plan
  4. Build & Test — AI tự chạy dotnet build và unit tests
  5. Đọc warnings/errors — AI parse output, tự sửa
  6. Loop cho đến khi pass — 0 warnings, 0 errors, tests xanh
  7. Report cuối cùng — tóm tắt thay đổi, file ảnh hưởng

🎯 Lợi Ích Thực Tế Của Skill

🔄 Nhất Quán

Mọi feature đều có log, transaction, error handling, unit test — không sót bước nào.

🧠 Plan Trước

Tránh AI code lung tung 200 dòng rồi mới nhận ra hướng sai. Plan giúp catch sớm.

🤖 Auto-Fix

AI tự đọc compiler warning, tự sửa, tự test lại. Bạn không cần xem terminal output.

📋 User Chỉ Review

Bạn không phải đọc error log, không debug. Chỉ duyệt plan + xem demo cuối cùng.

⚙️ Dùng Skill Trong Khóa Học

Trong khóa học có sẵn 2 skill chính (sẽ cài ở buổi 2):

  • revit-addin-planner — bắt AI plan kỹ trước khi code, output là markdown file chi tiết
  • revit-addin-implementer — code theo plan, auto-build, auto-test, auto-fix loop

Khi bạn gõ trong Claude Code:

$ /revit-addin-planner Tôi muốn add-in xuất schedule Door ra Excel $ /revit-addin-implementer # sau khi review plan xong

AI sẽ tuân thủ nguyên 7 bước ở khái niệm trên. Bạn chỉ duyệt plan ở bước 2 và xem report ở bước 7.

💡

Tinh thần chính: Việc của con người là review plan thật kỹ, không phải đọc warning thật kỹ. AI gánh phần khó, bạn gánh phần quan trọng (định hướng nghiệp vụ).

Bài Tập Về Nhà

Hoàn thành 3 bài này trước buổi 2. Mỗi bài không quá 15 phút với vibe-coding. Nếu mất hơn — bạn đang gõ tay quá nhiều, dừng lại và ra prompt rõ hơn.

📝 3 Bài Tập Tự Làm — Tạo Add-in Hoàn Toàn Bằng AI

Tất cả 3 bài tập đều phải dùng MVVM pattern + giao diện WPF. Code 100% sinh bằng AI (Claude Code / Cursor / Copilot), bạn chỉ làm prompt engineering và verify kết quả.

  1. Add-in "Duplicate Sheet" — Add-in cho phép user chọn một hoặc nhiều sheet trong project, nhập số lượng bản sao + prefix tên, sau đó tự động duplicate kèm theo views trên sheet. Giao diện WPF có danh sách sheet (DataGrid), input số lượng, preview tên sheet mới trước khi confirm.
  2. Add-in "Import Sheet from Excel" — Add-in đọc file Excel (.xlsx) chứa danh sách sheet (cột: Sheet Number, Sheet Name, Title Block), tự động tạo các sheet tương ứng trong Revit. Giao diện WPF có Browse Excel, preview bảng data từ Excel, chọn Title Block từ dropdown, button "Import All".
  3. Add-in "Dim Định Vị Cột" — Add-in tự động tạo dimension định vị tất cả cột trong mặt bằng (Structural Column) tới các grid line gần nhất theo phương X và Y. Giao diện WPF cho user chọn view mặt bằng, filter loại cột, tùy chọn dimension style, button "Generate Dimensions".

RevitAIKit — Bộ Agent Skills Chuẩn Production

Một bộ AgentSkills được thiết kế chuyên cho phát triển add-in Revit theo chuẩn công nghiệp. Cài 1 lần, dùng mãi mãi. AI tuân thủ quy trình chuẩn ở mọi bước — bạn không phải nhắc lại quy tắc cho từng prompt.

# Cài đặt RevitAIKit vào Claude Code (chỉ 1 lệnh) $ claude plugins install revit-ai-kit # Hoặc clone trực tiếp từ GitHub $ git clone https://github.com/your-org/revit-ai-kit ~/.claude/skills/

🛠️ 6 Skills Chính Trong Bộ Kit

/revit-plan
📋 Architecture Planner
Bắt AI plan kỹ trước khi code: file structure, transaction names, error cases, edge cases. Output markdown chi tiết để user review.
/revit-implement
⚡ Code Implementer
Code theo plan đã duyệt. Tự follow MVVM, DI, Serilog. Wrap transaction đúng chuẩn. Không bỏ sót error handling.
/revit-test
🧪 Test Writer
Tự viết unit test với TUnit, mock RevitAPI context. Run test loop cho đến khi 100% pass — bạn không động tay.
/revit-review
🔍 Code Reviewer
Review code AI vừa viết: memory leaks, transaction safety, naming convention, performance bottleneck. Tự refactor nếu cần.
/revit-package
📦 Installer Builder
Đóng gói MSI bằng WixSharp · Tạo PackageContents.xml cho Autodesk App Store · Setup CI/CD GitHub Actions.
/revit-debug
🐛 Auto Debugger
Khi build fail hoặc Revit crash, skill này tự đọc log Serilog, parse exception, sửa code, build lại — vòng lặp tự động.
✅
Chuẩn Hóa 100% Mọi add-in đều có log, transaction, error handling, test — không sót bước nào.
